# MP-E6-C11-T01 — Package skeleton, `Config`, ports, standalone CI

Plan: [../plan.md](../plan.md) §17.2–§17.6 and §17.10.

## Identity and outcome

- **User value:** the voice assistant can be used without aiur. From the first commit, a
  CI job shows that the core builds and tests alone and has no `Aiur.*` reference.
- **Deliverable:**
  - `packages/elixir/voice_converse/` Mix project (OTP app `:voice_converse`, Elixir version as
    `src/mix.exs`), deps `mint`, `mint_web_socket`, `jason`, `telemetry`; optional
    `websock_adapter`, `bandit` (for C11-T02).
  - `VoiceConverse.Config` struct + schema validation (plan §17.6), `VoiceConverse.child_spec/1`
    (empty instance supervisor for now), `VoiceConverse.availability/1`.
  - Behaviours `VoiceConverse.Ports.{BriefingSource, AgentChannel, CommandSource, Credentials}`
    with the callbacks of plan §17.4, `VoiceConverse.Briefing` struct (render/diff are C10-T02).
  - `VoiceConverse.Testing.{FakeBriefingSource, FakeAgentChannel, FakeCommandSource,
    StaticCredentials}`; `VoiceConverse.Redact` default redactor.
  - `src/mix.exs` path dependency `{:voice_converse, path: "../packages/elixir/voice_converse"}`.
    If `packages/elixir/` does not exist yet (MP-R7-C4-T03 not merged), create it using the
    form in migration-plan §5.
  - CI job `voice-converse-standalone`: `mix deps.get && mix compile --warnings-as-errors &&
    mix test` inside the package, plus `git grep -nE '\bAiur(Web)?\.'
    packages/elixir/voice_converse/lib` must print nothing. It also checks that `mix.exs`
    lists no aiur app.
- **Non-goals:** sessions, providers, transports (later tickets).

## Dependencies and blockers

- None in E6. It must land before C2-T01 and C6-T01 (they write into the package).
- Coordinates with MP-R7-C4-T03 (`packages/elixir/` form) and MP-R1-C1-T01 (manifest; the
  manifest entry is C11-T04).

## Chosen design notes

- `Config` validation fails at `child_spec/1`, not at the first session. A missing
  `transcript_root`, `credentials` or `briefing_source` is an error that names the field.
- Port deadlines (`brief` 100 ms, `details`/`ask`/`instruct`/`answer` 300 ms, `fetch` 50 ms)
  are constants in `VoiceConverse.Ports` and enforced by one `call_port/4` helper. On a
  timeout or exit it returns `{:error, :unavailable}`.

## Verification

| Test (package `test/`) | Expected |
| --- | --- |
| "config without transcript_root fails with the field name" | `{:error, %{field: :transcript_root}}` |
| "a port that exits is unavailable, not empty" | `call_port` → `{:error, :unavailable}` |
| "a port slower than its deadline is unavailable" | fake with a 500 ms sleep on `brief` |
| "the package has no aiur reference" (regression guard, labelled) | the grep step fails on a planted `Aiur.Foo` |

```bash
env -C packages/elixir/voice_converse mise exec -- mix test
env -C packages/elixir/voice_converse mise exec -- mix format --check-formatted
git grep -nE '\bAiur(Web)?\.' packages/elixir/voice_converse/lib && exit 1 || true
```

**Mutation check.** Make `call_port/4` return `{:ok, nil}` on exit: the unavailable test fails.
