# MP-E6-C11-T06 — Second provider adapter

Plan: [../plan.md](../plan.md) §17.3, E6-OQ20; bake-off MP-E6-C1-T01 amendment.

## Identity and outcome

- **User value:** a standalone user with only an OpenAI key, or only an ElevenLabs key, can
  use the package. aiur can switch providers by config.
- **Deliverable:** the adapter for the provider that did **not** win C1-T01:
  `VoiceConverse.Provider.OpenAIRealtime` (GPT-Live 1 over a server-side WebSocket; tools as
  function tools; `announce/3` via `conversation.item.create` + `response.create`; no audio
  stored; `store: false`) or `VoiceConverse.Provider.ElevenLabsAgents` (C2-T02/T03 scope). It
  passes the same `ProviderConformance` suite with recorded fixtures from the spike.
- **Non-goals:** provider-specific UI; changing the session or tool contracts.
