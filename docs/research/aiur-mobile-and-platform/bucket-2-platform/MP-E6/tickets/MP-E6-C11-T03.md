# MP-E6-C11-T03 — Standalone example host

Plan: [../plan.md](../plan.md) §17.5, §17.11; E6-OQ17.

## Identity and outcome

- **User value:** a developer with only an ElevenLabs (or OpenAI) key can talk to the voice
  assistant about their own work within a few minutes, without aiur. CI proves this on every change.
- **Deliverable:** `packages/elixir/voice_converse/examples/local_host/` (its own Mix project,
  `{:voice_converse, path: "../.."}`, `bandit`, `websock_adapter`):
  - `BriefingSource` from a Markdown file (`briefing.md`, sections → `Briefing` fields;
    file watch → `subscribe` updates); `details/3` sections `notes` (another file).
  - `AgentChannel` that writes `ask`/`instruct` records to `outbox.ndjson` and reads replies
    from `inbox.ndjson`. `fork_query/3` returns `{:error, :unsupported}` (`fork: :none`).
  - `Credentials` from `ELEVENLABS_API_KEY` / `OPENAI_API_KEY`; `transcript_root` `./transcripts`.
  - One page at `http://127.0.0.1:4100/` with the core JS client; README quick start (5 steps).
- **Non-goals:** CLI mic/speaker (E6-OQ17); `CommandSource` (left out on purpose, to show
  that an optional port can be absent).

## Verification

| Test (`examples/local_host/test/`) | Expected |
| --- | --- |
| "end to end with FakeProvider: start, briefing answer, draft, confirm, outbox" | outbox has exactly one instruct record after one confirm; none before |
| "no aiur on the code path" | `:code.which(Aiur.Application)` is `:non_existing`; the test fails if any `aiur` app is loaded |
| "Converse → listening with the fake provider ≤ 300 ms" (latency regression guard; real-provider target is research §7's ≤ 1 s) | measured time |
| "absent CommandSource is stated" | context has the gap line; no `list_open_commands` tool |

```bash
env -C packages/elixir/voice_converse/examples/local_host mise exec -- mix test
```

Manual: run with a real key, open the page, ask "what am I doing?", propose and confirm one
instruction, and check `outbox.ndjson` and `./transcripts/`. Record the result in the PR.

**Mutation check.** Make `propose_instruction` call `instruct` directly: the e2e assertion
"none before confirm" fails. (The page stands in for the human here. The core guard against
a non-client confirm is in C11-T02.)
