# MP-E6-C10-T05 — Side-query path

Research: [../realtime-convo-research.md](../realtime-convo-research.md) §5.3 path C.
Design input: `../side-query-findings.md` (from MP-E6-C10-T03).

## Identity and outcome

- **Bucket / feature / chunk:** 2-platform / MP-E6 / C10.
- **User value:** "why did it do that?" gets an answer from the agent's own memory in
  seconds, not after its current high-effort turn ends, and the agent is not interrupted.
- **Deliverable:** a `SideQuery` port (PROPOSED `Aiur.VoiceConversation.SideQuery`) with one
  adapter per harness that passed the spike (Claude fork first). `ask_agent(question)`
  (C5-T04) picks the path: side query when the harness supports it and the question is about
  the agent's reasoning or history; the queued consult (checkpoint delivery) when the answer
  needs the agent to act or to look at fresh state.
  - The fork runs with read-only tools, low effort, a 60 s hard timeout, one at a time per
    session, and the framing "Answer the operator's question from what you already know.
    Do not change files."
  - The answer returns as a `contextual_update` plus a spoken hand-off ("Here is what the
    agent's notes say: …"); the transcript records it as `side_query` with the fork's
    session id and cost.
  - The fork's transcript is deleted (or kept under the voice state dir) per the spike's
    findings; it never becomes the parent's history.
- **Non-goals:** instructions through the fork (a fork never edits, never sends).

## Dependencies and blockers

- **Spike:** C10-T03 must pass isolation (SQ-1, SQ-3, SQ-6).
- **Owner:** E6-OQ15 (cost per side query acceptable; on by default?).
- **Predecessors:** C5-T04 (`ask_agent` tool and consult record).

## Non-happy paths

- Fork fails or times out: fall back to the queued consult and say so.
- Parent session id unknown or transcript missing (`command.ex:50-60` fallback): no side
  query; queued consult only.
