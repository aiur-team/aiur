# MP-E6-C11-T05 — Read-only `fork_session` per harness (MP-R7 layer)

Plan: [../plan.md](../plan.md) §17.7 (capability matrix with evidence). Kevin, 2026-10-09
(verbatim): "Let's make sure that we have the fork feature wrapper model specific so that we
use the native fork for both Claude and Codex if they have those features as well as other
models."

## Identity and outcome

- **User value:** the voice assistant (and later the Executor) can ask a copy of the coding
  agent "why did you do that?" and get an answer in seconds. The real agent is never stopped,
  interrupted or changed. Each harness uses its own native fork where one exists.
- **Deliverable:** optional callbacks on the harness contract (`Aiur.Harness.Adapter`, today
  `Aiur.CodingAgent.Backend`; MP-R7 C2-T02 reserves optional callbacks):

  ```elixir
  @callback fork_capability() :: :native | :history_copy | :replay
  @callback fork_session(session_handle, %{prompt: String.t(), read_only: true,
                                           max_turns: pos_integer(), timeout_ms: pos_integer()}) ::
              {:ok, %{fork_id: String.t(), answer: String.t(), usage: map()}} | {:error, term()}
  @optional_callbacks fork_capability: 0, fork_session: 2
  ```

  | Harness | Mode | Implementation |
  | --- | --- | --- |
  | `claude-repl` | native | `claude -p --resume <session_id> --fork-session --permission-mode plan --allowedTools Read,Grep,Glob --disallowedTools "Bash Edit Write" --max-turns N --output-format json` in the parent's cwd. The answer comes from the result message; the fork id is recorded. |
  | `codex` | native | app-server `thread/fork` `{threadId, ephemeral: true, sandbox: "read-only", approvalPolicy: "never"}` (no `lastTurnId` when the parent is mid-turn), then `turn/start` with a read-only `sandboxPolicy` on the fork. On a separate app-server connection, never the parent's. |
  | `claude` (headless, `aiur-claude`) | replay until `aiur-claude` adds a fork | shared replay; a cross-repo request asks `aiur-claude` for a `thread/fork` over the Agent SDK `forkSession` |
  | `kimi`/`deepseek`/`openrouter` | history_copy | copy the session's message list into a one-shot completion loop with read tools only |
  | `muse`, `gemini`, future | replay | `Aiur.Harness.ForkReplay`: a fresh session of the same harness and model with the briefing text + last 40 redacted transcript entries (E4 `principal: :internal`, else `LiveConversation`) + the question; read-only tool set |

  `Aiur.Harness.fork(agent_ref, prompt, opts)` picks the adapter, enforces one fork per
  agent at a time and a hard timeout (default 60 s), and emits telemetry with mode, time and
  cost.
- **Non-goals:** any write through a fork; keeping forks (each is discarded: Claude fork
  session file deleted after the answer unless the spike says keep; Codex fork is
  `ephemeral`); the voice routing (C10-T05).

## Rules (all modes)

Read-only (no edit/write tools, no writing shell, no git writes); never writes to the parent's
transcript, session file or worktree; never pauses or interrupts the parent; secrets
redacted in replay input; usage counted in accounting like any other turn (`origin: :fork`).
