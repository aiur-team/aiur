# MP-E6-C14-T05 — Server speech parts for the cascade

Plan: [../plan.md](../plan.md) §20. Research: [../talk/research.md](../talk/research.md) §1.4, §1.6.

## Identity and outcome

- **User value:** a Claude user with an ElevenLabs key gets ElevenLabs voices and accurate live dictation, with the assistant text revealed letter by letter in step with the audio.
- **Deliverable:** `VoiceConverse.Cascade.TTS` and `.STT` behaviours with:
  - `elevenlabs_tts`: streaming text-in WebSocket with character alignment; alignment → `AgentTextTiming` (C13-T05).
  - `elevenlabs_stt`: realtime speech-to-text with partial and final transcripts.
  - `openai_tts` and `openai_stt` (transcription with deltas).
  - Barge-in: TTS stream closed and queued audio dropped on `Interruption`.
- **Non-goals:** ElevenLabs Agents (C2-T02/T03, a separate hosted-agent option).

## Acceptance criteria

- [ ] Alignment fixtures map to timings whose grapheme count equals the text sent to TTS, and offsets stay monotonic across chunk borders (chunk-relative times are made turn-relative).
- [ ] Partial STT text reaches the page as display-only (`UserTranscript{final?: false}`); only final text starts a model turn.
- [ ] Keys are fetched at connect and never logged.
- [ ] `openai_tts` emits `AgentTextTiming` with `estimated: true` (no provider timing, research §1.6).
- [ ] Each part reports usage for the running cost estimate (TTS characters, STT audio seconds; R23), and each part sets the provider's no-logging or no-storage option where the API has one (R22).
- [ ] Manual (operator, at review, cost under USD 1): Claude + ElevenLabs cascade for 2 minutes; record voice-to-voice time.

## Plan pass (2026-10-10)

**Key decisions**

- Part ids are `:elevenlabs_tts`, `:elevenlabs_stt`, `:openai_tts`, `:openai_stt`, the same spelling as the C14-T06 config example. Each part declares its credential id (`:elevenlabs` or `:openai`) for C14-T01 `needs`. Reason: one spelling across config, registry and doctor output.
- Two small behaviours, `VoiceConverse.Cascade.STT` and `VoiceConverse.Cascade.TTS`, with `start/2`, `push_audio/2` or `push_text/2`, `flush/1`, `cancel/1` and `capabilities/0` (input or output format, `timing: :chars | :none`). The C14-T04 turn engine calls them; the parts send events to the owner. Reason: the turn engine, barge-in and tool loop stay in C14-T04; this ticket adds only vendors.
- Transports reuse the C14-T04 seams: `mint_web_socket` for the ElevenLabs `stream-input` TTS socket, the ElevenLabs realtime Scribe socket and the OpenAI transcription session (`gpt-live-transcribe`, research §1.1a); the C14-T04 `Cascade.HTTP` seam for OpenAI TTS (`/v1/audio/speech`, streamed PCM). Reason: plan §17.2 limits core dependencies, and fakes plug into the same seams.
- Turn end comes from the vendor: Scribe in VAD commit mode (`COMMITTED_TRANSCRIPT` is final, research §1.4c) and OpenAI server VAD (`...transcription.completed` is final). Partials map to `UserTranscript{final?: false}` and go to the page only. Reason: R10 live text and the V5-style rule that only final text starts a turn.
- One TTS socket per assistant turn. The part opens it when the final user text arrives, in parallel with the model's first token, and closes it at turn end or on `Interruption`. Reason: no idle socket against the 20 s `inactivity_timeout`, and a clean cut on barge-in (no queued audio survives a closed socket).
- Both TTS parts emit 24 kHz PCM (`pcm_24000` from ElevenLabs, `pcm` from OpenAI), the C2-T01 widened `audio_out`. Reason: no resampling on the output path; 44.1 kHz PCM from ElevenLabs may need a higher plan tier (implementer checks).

**Risks**

- ElevenLabs alignment times are relative to each chunk, and `normalizedAlignment` can differ from the sent text (numbers spelled out) → use `alignment`, not `normalizedAlignment`; add the summed audio duration of earlier chunks to each offset; property test over random chunk splits.
- Echo or room noise makes a server partial look like barge-in → raise `Interruption` only on a partial with at least 2 words or on the vendor's speech-start event; the page keeps browser echo cancellation on (research §2.4, C13-T04).
- Billing does not stop at once on cancel → close the socket or Mint connection, do not only drop frames; usage for a cut turn counts what was sent.
- A key leaks through an error body or a crash report → `Credentials.fetch/2` at connect, key only in the header list, never in process state; map HTTP and socket errors to `Events.Error` codes; the sentinel-key test checks logs and state.
- Vendor frame shapes drift from the documented examples → parsers ignore unknown events; the manual run captures one redacted live stream per vendor as a new fixture.

**Test strategy**

- Unit, fakes only, no key, cost zero: `test/voice_converse/cascade/{tts,stt}/*_test.exs`. A fake WebSocket transport and the fake `Cascade.HTTP` replay documented frames, split at random points (StreamData). `Testing.StaticCredentials` gives a sentinel key. Cases: alignment to timings (property), estimated timing for OpenAI TTS, partial versus final, interruption closes the stream and drops queued audio, usage telemetry, privacy options in the connect request, sentinel key absent from `ExUnit.CaptureLog` output and from `:sys.get_state/1`.
- Integration: one session test with the real session, the C14-T04 cascade, a fake LLM and these parts on fakes. It checks partial → no LLM call, final → one LLM call, and `Interruption` → no `AgentAudio` after it → transcript `interrupted?: true` with the heard prefix (C13-T05). Browser playback is tested in C13-T04, not here.
- Manual with real keys (operator, at review): Claude + ElevenLabs cascade (`elevenlabs_stt`, `anthropic:claude-haiku-5-5`, `elevenlabs_tts`) for 2 minutes. Cost cap USD 1 (expected under USD 0.20: about 2,000 TTS characters at USD 0.04-0.08 per 1K, Scribe at USD 0.39/hour, Haiku tokens). Record voice-to-voice time per turn and one barge-in. OpenAI parts: one 1-minute run under USD 0.25 if an OpenAI key is at hand, else fixture-only.
- Mutation and regression guards: (1) start a turn on partial text → "partial transcript does not start a turn" fails. (2) Drop the chunk-offset accumulation → "elevenlabs alignment becomes letter timings" fails on multi-chunk fixtures. (3) Keep the TTS socket open on `Interruption` → "interruption closes the TTS stream" fails.
