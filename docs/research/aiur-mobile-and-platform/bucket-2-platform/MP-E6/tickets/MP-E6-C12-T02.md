# MP-E6-C12-T02 — Fork the Executor session

Plan: [../plan.md](../plan.md) §18.2, §18.4. Builds on C11-T05 (`fork_session/2`).

## Identity and outcome

- **User value:** a voice question about the Executor's reasoning ("why did you hold #3456?")
  is answered from the Executor's full context in seconds. The Executor loop is not stopped,
  interrupted or changed.
- **Deliverable:**
  - `fork_session/2` accepts a session handle without a running aiur agent (C11-T05 keys
    one-fork-at-a-time by agent ref; add `{:executor, consumer_id}`).
  - `Aiur.Executor.Fork.query(question, opts)`: reads the C12-T01 handle and calls the native
    fork. Claude Code argv: `-p --resume <id> --fork-session --tools Read,Grep,Glob
    --permission-mode plan --strict-mcp-config --no-session-persistence --max-turns N
    --output-format json`; env: recorded `CLAUDE_CONFIG_DIR`, `GITHUB_TOKEN`/`GH_TOKEN`
    and aiur RPC credentials removed; cwd: recorded cwd. Codex: `thread/fork` ephemeral,
    read-only, `approvalPolicy: never`, own app-server process.
  - Handle `unknown` or a fork error → `{:error, :executor_fork_unavailable}`; 60 s timeout
    kills the process.
- **Non-goals:** delivery to the live Executor (C12-T03); writes of any kind.

## Acceptance criteria

- [ ] The Claude argv has every flag above; the env has no GitHub token.
- [ ] Parent untouched: the Executor session file hash and `git status --porcelain` of its cwd
      are equal before and after a fork (fake CLI and one real manual run).
- [ ] No new session file appears in the profile's project directory after a fork.
- [ ] A second concurrent Executor fork returns `{:error, :fork_busy}`.
- [ ] Manual: one real fork of an Executor blocked in `executor-wait`; record answer, time and
      cost in the PR (spike SQ-6 for this shape).
