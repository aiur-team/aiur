# MP-E6-C11-T04 — aiur host adapter layer

Plan: [../plan.md](https://github.com/aiur-team/aiur/blob/de341053cc16d2e6096a3a0d0fbacb43ef9f6eb0/docs/research/aiur-mobile-and-platform/bucket-2-platform/MP-E6/plan.md) §17.8, §17.10.

## Identity and outcome

- **User value:** aiur uses the package through a thin, reviewable layer. Every aiur rule
  (config keys, key storage, alerts, capability) stays in aiur, and the package stays clean.
- **Deliverable (`src/lib/aiur/voice_converse/host/`):**
  - `Config.build/1` (with C3-T01): `voice.conversation.*` + provider choice → `%VoiceConverse.Config{}`,
    `transcript_root` from `Config.Paths.voice_conversation_state_dir/0`, redactor
    `&(Aiur.SecretRedactor.redact(&1) |> Aiur.SecretRedactor.redact_urls())`, roles dir and glossary.
  - `Credentials`: ElevenLabs key through the MP-R5 voice facade; OpenAI key through the
    config/env path that C11-T06 names. The key is never cached.
  - `Telemetry`: attaches handlers. `provider_cleanup.give_up` → `Aiur.Alerts.emit_custom/3`;
    `cost_cap.reached` → an attention line.
  - `Capability`: `voice.conversation` = `VoiceConverse.availability/1` + aiur rules
    (capability-matrix row).
  - Composition root: add `VoiceConverse.child_spec(Aiur.VoiceConverse.Host.Config.build!(cfg))`
    when the component is enabled (MP-R1-C8-T08 pattern; until assembly exists, next to
    `Aiur.ElevenLabs.Quota` in `src/lib/aiur.ex`).
  - `components.json`: entries `voice-conversation-core` and `voice-conversation`, as plan
    §17.10. Allowlist: none needed. A needed allowlist row is a design failure; report it.
- **Non-goals:** BriefingSource/AgentChannel/CommandSource implementations (C4-T02, C5-T03 + C5-T06 (worker delivery via E7),
  C5-T04, C5-T05, C10-T02, C10-T04, C10-T05 own them).
