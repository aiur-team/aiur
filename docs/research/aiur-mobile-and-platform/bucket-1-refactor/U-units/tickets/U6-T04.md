# U6-T04 - Shared status read model with age

> Answers **RQ-U6-STATUS-MODEL**, the predecessor of MP-R1-C9-T14 (move the
> read verbs after U6's shared status read model).

## Identity and outcome

- Bucket 1, prior unit U6 (R2, KTD4; AGENTS.md "If a surface computes an age,
  it renders the age").
- **User value:** `aiur status`/`aiur agents` and the dashboard show the same
  values, and each value says how old it is.
- **Deliverable:** `StatusReport.snapshot_input/1` carries the full field set;
  each field group carries `observed_at` and `age_ms`; CLI and web render age;
  Codex retry cause/time is labelled "since this daemon start" (decision below).
- **Non-goals:** no persistence of retry state (decision); no new page; the
  web cache loader fix is U6-T05.

## Dependencies and blockers

- U0-T01; U2-T04 (per-ticket `waiting` fields with since).

## Verified starting point (`58854d4c8`)

- CLI and web both read `SnapshotStore.read` (`orchestrator/snapshot_store.ex:213`):
  CLI via `StatusReport.fleet_view` → `agent_statuses` (`agent_control_cli.ex:112-150`);
  web via `Orchestrator.dashboard_snapshot` (`aiur_web/presenter.ex:25`) and
  `PayloadLoader` (`operator_control_center/payload_loader.ex:162`).
- Both fed by the allow-list `StatusReport.snapshot_input/1`
  (`status_report.ex:203-238`), which **omits** `orphaned_agent_reap_count`,
  `startup_claim_reconciliation_complete?`, `dispatch_capacity_sample`,
  `claimed`, `model_fallback_waiting`, `blocked_ticket_ids` (orch-b-01).
- Freshness is snapshot-level only (`status/reason/observed_at/age_ms`,
  :62-66, :101-106); CLI prints `age_seconds` only when stale
  (`agent_control_cli.ex:177-184`).
- Codex retry state is memory only: `State.retry_attempts`
  (`retry_engine.ex:596-610`; monotonic `due_at_ms` :576); thrash budget
  `dispatch_recovery.codex_thrash_budget` (`state.ex:10-12`). Only
  `Codex.StartupFailure.record` persists, per launch, as forensic evidence.

## Chosen design

- Replace the allow-list with the list of fields any renderer reads (grep CLI
  and web renderers; add the six missing). Keep one list in `status_report.ex`.
- Field groups (fleet, capacity, per-ticket, retries) carry
  `observed_at` + `age_ms` from the time the orchestrator computed them (the
  snapshot already has one; groups computed at other times get their own).
- CLI: always print the snapshot age in `aiur status`; per-ticket age from U2-T04.
  Web: render the same ages where those fields are shown (presenter only).
- **Decision (without owner):** do not persist Codex retry state. Label retry
  rows "since daemon start <time>" and point to the startup-failure file as
  forensic evidence. Persisting would add a durable store for a value that is
  recomputed on the next failure (ponytail).

## Implementation steps

1. Field list; the six fields; group ages.
2. CLI renders; web presenter renders.
3. Retry label.
4. Docs: `website/docs-app/reference/cli.md` `status`/`agents` samples;
   dashboard guide page if it shows a sample.
5. Tests.

## Non-happy paths

- **Snapshot unavailable:** existing `status: :unavailable` path; render
  "unavailable", never zeros (AGENTS.md unknown-path rule).
- **Group computed in a previous tick:** its own `observed_at` shows the older age.

## Compatibility and rollout

JSON additive. Text output changes (docs updated). Rollback: revert.
