# U1-T02 - Two-instance stop witness

## Identity and outcome

- Bucket 1, prior unit U1. Repair #2846 (`12055bff2`) is merged.
- **User value:** an operator who runs two Aiur instances (different
  `AIUR_INSTANCE_KEY`) can stop one without killing the other's agents.
- **Deliverable:** (a) an automated test that runs the real `reap_aiur_agents`
  against real child processes for two instances; (b) one recorded live check
  with two instances on the dev machine.
- **Non-goals:** PID-recycle hardening (issue #2844) stays a separate ticket;
  no change to pidfile naming.

## Dependencies and blockers

- Blocked by U0-T01. Concurrent with U1-T01, U1-T03.
- Interlock: MP-N2 adds launcher commands to `aiur-engine.sh`; recheck line
  numbers at the implementation SHA.

## Verified starting point (`58854d4c8`)

- `packaging/npm/aiur-cli/libexec/aiur-engine.sh`: `cmd_stop` :3620; pidfile
  chosen by `agent_pidfile_from_instance_record` (:1883-1906, called at :3631)
  - record field `AIUR_RECORD_AGENT_TMPFILE` (written :1642), else strict legacy
  fallback; early "nothing running" return :3643-3653; scoped reap :3693-3696 →
  `reap_aiur_agents` (:1511) → `agent_pid_matches` (:1491, liveness + command
  substring only). Pidfile created at :946, named after the launcher PID.
- `src/test/aiur_engine_stop_pidfile_test.exs` (105 lines) stubs
  `reap_aiur_agents` (logs `REAP:` only), `kill_beams_matching`,
  `probe_node_liveness`, `sweep_*`, and `tmux` (lines 28-38). It proves only
  which pidfile is selected and deleted (:100-103). **No real process is signalled.**

## Chosen design

- Keep the existing test. Add a second test in the same file that does **not**
  stub `reap_aiur_agents` or `agent_pid_matches`. It starts two `sleep` children
  whose command line contains the substring `agent_pid_matches` expects (one
  per instance), writes each PID into that instance's pidfile, runs `cmd_stop`
  for instance A with the other heavy functions still stubbed, then asserts A's
  child is gone and B's child is alive.
- Live check: two real instances (`AIUR_INSTANCE_KEY=a`, `=b`) in `--bg` mode
  with one agent each on sandbox tickets; `aiurdev stop` with key `a`; capture
  `aiurdev agents` for `b` before and after. Record in the U1 evidence note.

## Implementation steps

1. Read `agent_pid_matches` to get the exact substring rule; build the child
   command to match it (e.g. `exec -a` or a wrapper script name).
2. Add the test; clean up both children in `on_exit`.
3. Run it; then mutation-check.
4. Run the live check; record output (no hostnames or IPs).

## Non-happy paths

- **Orphan children on test failure:** `on_exit` kills both PIDs.
- **Recycled PID:** out of scope (#2844); note the limit in the test comment.
- **Live check on a busy fleet:** check load first; use sandbox tickets only;
  never run `--test` from an agent workspace (AGENTS.md guard).

## Compatibility and rollout
