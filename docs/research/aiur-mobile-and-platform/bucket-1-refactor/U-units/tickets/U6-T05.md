# U6-T05 - Non-blocking cache loader and unknown cap

## Identity and outcome

- Bucket 1, prior unit U6.
- **User value:** one slow dashboard load no longer blocks every other page
  request behind it; when the agent cap is unknown the analytics page says so
  instead of showing a made-up number.
- **Deliverable:** `ControlCenterCache` runs `loader.()` outside `handle_call`
  and uses bounded call timeouts; `cap_facts` uses `cap: nil` → "unknown".
- **Non-goals:** no cache TTL change; no new page.

## Dependencies and blockers

- U0-T01. Independent of U6-T04 (different files).

## Verified starting point (`58854d4c8`)

- web-rest-02: `aiur_web/control_center_cache.ex:30, 36` use `:infinity` calls
  and run `loader.()` inside `handle_call` (:52), so a slow loader blocks all callers.
- web-occ-07: `operator_control_center/analytics/presenter.ex:1038, 1078-1084`
  `cap_facts` falls back to `safe_cap()` - a default value - when the cap is unknown.

## Chosen design

- Cache: on miss, start the load in a `Task` (supervised by the existing task
  supervisor if one is used in `aiur_web`; check) and reply to waiting callers
  when it finishes; concurrent callers for the same key join the same load.
  Calls use a bounded timeout (5 s). On timeout the cache returns the last
  cached payload marked `stale: true` (or an explicit unavailable payload when
  none exists), keeping `fetch/4 :: map()`. Both callers in
  `payload_loader.ex:92-116` today `catch :exit, _ -> load_uncached(providers)`,
  which would re-run the slow load per LiveView; change that fallback to use the
  stale/unavailable payload, never `load_uncached`.
- Cap: `cap: nil` when unknown; renderer prints "unknown" (and charts skip the
  cap line).

## Implementation steps

1. Cache refactor (keep public API).
2. `cap_facts` nil; renderer and chart.
3. Tests.

## Non-happy paths

- **Loader crashes:** waiting callers get `{:error, reason}`; next call retries.
- **Many keys at once:** one task per key; bounded by the number of pages.

## Compatibility and rollout

No config. Rollback: revert.
