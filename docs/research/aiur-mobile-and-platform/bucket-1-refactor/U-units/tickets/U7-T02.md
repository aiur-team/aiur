# U7-T02 - Cut the Linear tracker (conditional)

## Identity and outcome

- Bucket 1, prior unit U7 (R9, R10, D4).
- **User value:** if no operator uses Linear, about 1,000 lines of code, a
  skill, an example and their tests stop costing review and refactor time, and
  MP-R1-C7's tracker split shrinks to GitHub + memory.
- **Deliverable:** removal of every Linear path listed in U7-T01's starting
  point, including config keys, the dynamic tool, the skill, the example, docs
  and tests; `aiur` gives an actionable error for `tracker.kind: linear`.
- **Non-goals:** no removal of the generic tracker contract; no change to GitHub or memory trackers.
- **If the owner says keep:** close this ticket as "won't do" and record it in
  `features.json`; that unblocks its dependents.

## Dependencies and blockers

- **Blocked on the owner decision.** U7-T01 supplies the census.
- U5-T04 (tracker facade outcome shapes settle first; avoids rebasing).

## Verified starting point (`58854d4c8`)

See U7-T01 "integrations-03". Key edge: `tracker.ex:166` makes Linear the
**fallthrough default** - the cut must make the default explicit (memory or an
error) and test it.

## Chosen design

- Config validation: `tracker.kind: linear` → error "Linear tracker support
  was removed in <version>; use github or memory" (existing error style in `config.ex`).
- `tracker.ex`: no fallthrough to Linear; unknown kind → the same validation error.
- Remove: `src/lib/aiur/linear/`, `codex/dynamic_tool/linear_graphql.ex` and its
  registration, `.codex/skills/linear/`, `src/examples/workflows/linear-codex.*`,
  init questions/templates for Linear, layout and errors branches, docs rows
  (`reference/configuration.md` - one entry per key removed; `index.md`,
  `skills.md`, `AGENTS.md`, `.aiur/examples/config.example`), tests.
- `scripts/check-config-docs.py` must still pass (keys removed from both sides).

## Implementation steps

1. Config error + explicit default; test.
2. Delete code, skill, example, init branches; fix compile.
3. Docs; config-docs checker.
4. Report moved vs removed lines (removed only; D5).

## Non-happy paths

- **An operator still has a Linear config:** startup fails fast with the
  actionable error (not a crash later).
- **Workspaces keyed by Linear `project_slug`:** layout branch removed; existing
  directories are left on disk (no deletion of operator data).

## Compatibility and rollout

Breaking for Linear users - release notes must say so. Rollback: revert.
