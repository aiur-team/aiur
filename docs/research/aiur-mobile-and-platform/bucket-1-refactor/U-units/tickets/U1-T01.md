  sandbox**, and they pass silently when `bwrap` is absent. No workflow installs
  bubblewrap, so CI likely never runs them. The e196 one-off probe was never committed.

## Chosen design

- **No-send witness:** reuse the module's existing injection points. If
  `OperatorDispatch` is reached through a configurable function or the test
  can start a fake agent chat target, assert it receives nothing. If there is
  no seam, use a `Registry`/process that would receive the `AgentChat.send`
  message and `refute_receive` with a short timeout plus a positive control
  (the authorized case does deliver). Do not add a new behaviour for this.
- **Sandbox env witness:** a real-bwrap test that runs `env` inside the sandbox
  with three synthetic names set in the parent (`GITHUB_TOKEN`, `GH_TOKEN`,
  `GITHUB_APP_PRIVATE_KEY`) and asserts none appears in the child output while
  `AIUR_GITHUB_CREDENTIAL_FILE` does. Tag it `@tag :bwrap`; when `bwrap` is
  missing, the test is **skipped with a reason**, not passed.
- **Decision:** no CI bubblewrap install in this ticket (ponytail: the tag makes
  the gap visible; adding a package to CI images is a separate infra change).
  Record the gap in the U1 evidence note.

## Implementation steps

1. Add the no-send test next to :130-141 in `operator_identity_test.exs`:
   unauthorized coalesced batch → 401, no delivery observed; authorized batch →
   one delivery (positive control).
2. Add the env test to `command_runner_budget_test.exs` near :84.
3. Run both at the implementation SHA. If green: mutation-check them. If red:
   repair in the owning file and record red/green.
4. Update `synthesis/merged-main-e196-u1-focused-witnesses.md` with a line per
   witness (or the new U0 review record).

## Non-happy paths

- **Flaky refute window:** use the positive control to prove the delivery path
  is wired in the same test setup; keep the refute window ≤ 200 ms.
- **bwrap present but user namespaces disabled:** the test must skip with that
  reason, matching how existing real-bwrap tests detect it.
- **Secrets in test output:** use synthetic values only (`ghp_test_…`).
