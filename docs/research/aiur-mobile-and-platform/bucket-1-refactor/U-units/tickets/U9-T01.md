# U9-T01 - Net LOC census

## Identity and outcome

- Bucket 1, prior unit U9 (R14, D5, KTD8).
- **User value:** each refactor phase reports how many lines were really
  removed, separately from lines moved, so no PR claims a move as a saving.
- **Deliverable:** `--census <base> <head>` mode in `scripts/check-file-size.py`
  (from U0-T03) printing, per area (source, test, docs, generated/vendor,
  other): lines at base, at head, added, removed, and moved (rename/copy pairs
  detected by `git diff -M -C` are counted as moved, not removed + added).
- **Non-goals:** no CI enforcement; no saving claims (instrumentation only).

## Dependencies and blockers

- U0-T03 (same counter and binary/symlink rules - one counter, not two).

## Verified starting point (`58854d4c8`)

- No LOC census tool in `scripts/` or `src/lib/mix/tasks/` (11 tasks).
- Areas: `src/lib` = source; `src/test`, `**/*test*` = test; `docs/`,
  `website/docs-app/`, `**/*.md` = docs; `src/priv/static/vendor/`,
  lockfiles, `*.min.js` = generated/vendor; rest = other. (Rules in one table in
  the script; adjust only by PR.)

## Chosen design

- Reuse the U0-T03 counter on both trees. Moves: parse
  `git diff -M -C --numstat -z base head`; a rename pair contributes its
  unchanged lines to "moved" and only the diff lines to added/removed.
- Output: a markdown table (paste into PR bodies) and `--json`.

## Implementation steps

1. Census mode; area table; move detection.
2. Extend `scripts/test-check-file-size.sh` with census cases.

## Non-happy paths

- **Binary changes:** listed by count, not lines.
- **Rename across areas** (source → test): counted moved in the source area of
  the base path; documented.

## Compatibility and rollout

Developer tool only.

## Verification

| Case (`test-check-file-size.sh`) | Expected |
| --- | --- |
| delete a 100-line source file | source removed 100, moved 0 |
| `git mv` a 100-line file unchanged | moved 100, added 0, removed 0 |
| move + edit 10 lines | moved 90, added/removed 10 |
| add a vendored `.min.js` | generated/vendor added |
