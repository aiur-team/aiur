## Chosen design

The structure is fixed now; the presentation is DESIGN-R1's.

- `ComponentDirectory.vue` (PROPOSED, `.vitepress/theme/components/`) takes
  `DirectoryData` from C10-T02 and renders:
  1. intro (approved copy);
  2. optional filter "optional only" (if Q3 approves it) — client-side, no state
     persisted beyond the page;
  3. groups (Q3) of entries; each entry shows exactly the Q1-approved fields in the
     approved order; `requires`/`optional` render as in-page anchor links
     (`#component-<id>`); `config` names link to
     `/reference/configuration#<section>` (anchor generated by VitePress from the
     section heading — C10-T04 verifies each anchor exists); `docs` links use the page
     path; no source-path links (Q8 default) unless approved;
  4. the Mermaid diagram if Q6 approves it, generated from the manifest's
     minimum-combination data (not hand-written): nodes are components, edges are
     `requires`, limited to the approved subset;
  5. "Planned": entries from `data.planned`; if empty, the approved one-sentence
     empty-state copy, never an empty table (DESIGN-R1 §3 states);
  6. a footnote with `generatedFrom` (manifest hash).
- Narrow screens: entries stack, no horizontal scroll (DESIGN-R1 §3 states table).
  Implement with CSS grid → single column under the default theme's mobile breakpoint
  (`768px`, the VitePress default theme `--vp-layout` breakpoint; confirm in
  `custom.css` before use).
- Badges: one CSS class per status; colors from theme variables in `custom.css`, both
  themes.
- Component without a docs page: the docs link is omitted (DESIGN-R1 §3: the build
  check fails only on a broken link, not a missing one).

## Non-happy paths

- **Design not approved:** ticket stays blocked; C10-T02's plain list remains unlisted.
- **Approved field not present in the manifest:** add it through C10-T01's schema rules
  in this PR; never render a placeholder value.
- **Mermaid render failure:** the diagram is enhancement; a render error must not hide
  the table (place the diagram after the table and wrap it so a failure leaves the
  rest of the page intact).
- **Accessibility:** badges carry text, not color alone; links have discernible text;
  `npm run test:brand` must pass.
