## Non-happy paths

- **FK failure backoff:** `handle_write_failure/…` counts foreign-key failures and
  backs off (`:652-698`). It moves to `EventRows` with its threshold; the
  `handle_write_failure_for_test`/`reset_fk_failures_for_test` hooks delegate.
- **Transactions:** `write_*_in_txn` functions run inside `Db.with_transaction`
  opened by the caller. Do not open a new transaction in the moved code.
- **Redaction and bounds:** `LiveConversation` redacts credential fields and caps the
  JSON wire size (tests `:522`, `:731`, `:774`). These live in ingest and `public/…`;
  keep them on the same path.
- **Restart detection key:** `{__MODULE__, :projection_started, …}` (`:683`) must keep
  `Aiur.LiveConversation` as the key; do not move `projection_restarted` out.
- **Live e2e secrets:** the e2e helpers read Linear API keys from env; moving them to
  support must not print or log them.
