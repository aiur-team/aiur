- The shim sources its two libraries from its resolved real directory, like the
  engine. Shared helper code (a shim test fixture builder) stays in one test file and is
  reached through `Code.require_file` only if the existing tests already do so;
  otherwise copy nothing and keep each test file's own setup.
- The two new shim libraries are dev-only. They are not in the npm package.

- **Agent-workspace `--test` guard:** it must refuse before any reset, clear, stop or
  launch. The "agent workspace --test is blocked before reset" tests guard order.
- **Symlink resolution:** the shim is run from a `PATH` symlink and from paths with
  spaces ("rebuild command ... from a path with a space"). Source with quoted resolved
  paths.
- **Release scripts:** the npm tarball must not change; `npm pack --dry-run` lists the
  same files as before.
