  quota security boundary for every agent. Splitting the 3,403-line shell script

## Non-happy paths

- **Bypass by edit:** an agent can already edit its installed `gh`; runtime sourcing
  would add new writable files and an env-var path to hijack. That is why the design
  assembles at compile time. Do not add `AIUR_*` variables that name a part directory.
- **Remote workers:** `remote_install_script` embeds the scripts as text. It keeps
  calling the same `@scripts` content, so remote installs receive the assembled file.
- **Stale broker:** unchanged; `maybe_log_stale_broker` moves as is.
- **Fail closed:** "a paginated API call fails closed when its request body comes from
  a file", "a malformed broker grant refuses the real gh command" and the merge-gate
  tests must stay green with no assertion edits.
- **Recompile:** `@external_resource` on every part, so editing one part recompiles
  `AgentGitHubGuard`. A missing part fails compilation (`File.read!`).
