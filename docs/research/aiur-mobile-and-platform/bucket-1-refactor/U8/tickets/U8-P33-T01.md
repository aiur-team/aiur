  to review. Duplicate guidance between `SKILL.md` and `references/executor.md`

- **Merge rule for duplicates:** diff each pair. Identical text keeps one copy. Where
  the two copies differ, keep every distinct sentence in the one copy. Never drop a
  rule to save lines.
- `SKILL.md` keeps the "Read now" routing so the content is still loaded at the same
  step of a run.
- Scripts: `source "$(dirname "${BASH_SOURCE[0]}")/lib/…"` so the Codex symlink path
  still resolves (test `:236-255` covers symlinked discovery).

1. PR 1 (skill text): create the four references; move sections; merge duplicates by
   the rule above; add routing lines in `SKILL.md` and `executor.md`.
2. In the same PR, re-point each content assertion to the file that now holds the
   text (`aiur_run_authority_skill_test.exs`, `aiur_run_allowed_contributors_skill_test.exs`,
   `aiur_agent_skill_test.exs:138,251`). Add one test: every `references/*.md`

3. Fix inbound anchors: `git grep -n "aiur-run/SKILL.md#\|references/executor.md#"`
   and update each link.
4. PR 2: split `executor-retrospective.sh` into `lib/`; split its test into three
   files; add the two new test files to the CI step at `ci.yml:185` (or make that
   step loop over `tests/executor-retrospective*_test.sh`).
5. PR 3: move the pure functions of `capture-dashboard.mjs`; keep the re-exports so
   `capture-dashboard_test.mjs` imports do not change.
6. PR 4: move `gh` access out of `land_watch.py`.
7. PR 5: split `aiur_agent_skill_test.exs` by subject; keep `async` settings and the
   `@repo_root` attribute in each file.

## Non-happy paths

- **Lost context:** a moved section that `SKILL.md` no longer routes to is not read
  during a run. Step 1 adds a routing line for each moved section; review checks the
  count of `references/` links.
- **Broken anchors:** other skills (`aiur-debug`, `aiur-intro`, `aiur-meta`,
  `aiur-monitor`) and docs link into these files. Step 3 covers them.
- **Codex symlinks:** `.codex/skills/aiur-run` is a directory symlink. New files in
  the same tree are visible through it; no new symlink is needed.
- **Shell sourcing:** `set -euo pipefail` and the lock `trap` stay in the entry
  script; libraries define functions only, so sourcing has no side effects.
- **Exit codes:** `cli_check` / `visual_check` exit 67 on a missing daemon URL (test
  `:278-290`). Keep the code path unchanged.
