## Non-happy paths

- **Process boundary:** functions call `Process.send_after/3`, `Task` and monitors
  on behalf of the orchestrator. Moving them must keep the caller process the
  orchestrator (no `spawn` wrappers added). "CPU headroom recovery integration" and
  the readiness timeout tests guard timer ownership.
- **Durable budgets:** `persist_lifetime_trip` and `DispatchBudgetStore` writes keep
  their order relative to the state update (a crash between them must not unbill).
- **Alert dedup:** emit/clear pairs must stay in one module so the dedup key is
  defined once.
- **Fallback binding:** `record_fallback_binding_constraint` and
  `ModelAvailability` interplay is shared with `rate_limit_fallback.ex`
  (U8-P28-T03); do not move it there in this ticket.
