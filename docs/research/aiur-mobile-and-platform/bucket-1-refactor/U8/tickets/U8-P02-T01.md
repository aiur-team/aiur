## Non-happy paths

- Closures built in `ToolExecutor.build/3` capture issue and opts. Moving their bodies
  must keep the capture: pass the same values as arguments; do not read them again from
  `Process` dictionary or config at call time.
- `safe_coordination_call` and `safely_open_attention` rescue failures so a tool call
  never crashes the turn. Keep each rescue with its call site.
- `pause_for_account_usage_wait` and before-run waits block in a receive. Keep the receive
  in the same process; do not move it behind a `GenServer.call`.
- The runner registers a name (`registered_name/1`); keep the registry key unchanged.
