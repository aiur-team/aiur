## Chosen design

- Partials: `src/priv/static/css/NN-<surface>.css`, `NN` two digits giving cascade order
  (e.g. `00-fonts-shell.css`, `10-build-order-catalog.css`, … `90-panels-modals.css`).
  Cuts fall only at existing section comments or, inside a section over 500 lines, at a
  top-level rule boundary between two sub-section comments. About 24 files.
- `StaticAssets`: replace the one path with `@dashboard_css_parts` = sorted
  `Path.wildcard(Path.expand("../../priv/static/css/*.css", __DIR__))`; one
  `@external_resource` per part; `@dashboard_css Enum.map_join(parts, &File.read!/1)`.
  Add `dashboard_css/0` returning the string for tests.
- `@external_resource` with a wildcard does not recompile on a new file; add
  `def __mix_recompile__?` comparing the wildcard result with the compiled list (standard
  Elixir hook), so adding a partial recompiles the module.
- Rationale: smallest change that keeps one URL, one response and zero runtime work; the
  module already embeds the file at compile time.
- Invariant: the assembled bytes at merge equal the old `dashboard.css` bytes exactly.

## Implementation steps

1. Cut the file into partials with a one-off script that writes line ranges at the chosen
   boundaries; assert `cat css/*.css` equals the old file byte for byte.
2. Change `StaticAssets` as above; delete `dashboard.css`.
3. Update the five direct file readers to call `AiurWeb.StaticAssets.dashboard_css/0` (Elixir
   tests) or to concatenate `priv/static/css/*.css` in sorted order (packaged check script).
   Update `compile_time_paths_test.exs` expected attribute lines.
4. Add `src/priv/static/css/README.md` (5 lines): order rule and "do not create a file above
   500 lines".

## Non-happy paths

- Cascade order: a wrong sort order changes rendering silently. Sorting is lexical on
  two-digit prefixes; the byte-equality check in step 1 and the test below guard it.
- A partial with no trailing newline would merge two rules' lines; the cut script writes
  whole lines, and the test checks every part ends with `\n`.
- The release must contain `priv/static/css/`; `mix release` copies `priv/` whole. The
  packaged check proves it.
- Theme test reads hardcoded colors; it now reads the assembled string, same content.
