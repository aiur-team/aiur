## Non-happy paths

- **Crash recovery:** interrupted migration and ledger transfer recovery
  (`recover_interrupted_migration`, `recover_ledger_transfer`) must run in the same
  order at the same point of `refresh`. Tests `:281-711` guard this, including the
  marker outside the source tree (`:530`) and concurrent first finding appends
  (`:712`).
- **Path safety:** `ensure_state_path_safe`, `state_path_components_safe` and the
  symlink checks move with the code that needs them; no call loses its check.
- **Secrets:** `git_auth_env` carries the token only in env (test `:1568`); keep
  `format_error` redaction.
- **WIP data loss:** `guard_destroy` must refuse when a save fails or times out
  (tests `:170-260`, `:354-470`). The refusal path stays in the facade.
- **Process kill:** a timed-out save kills its command (test `:445`); `command.ex`
  already owns that; do not duplicate it.
