## Chosen design

| PROPOSED path (under `packaging/npm/aiur-cli/libexec/`) | Takes | Est. lines |
| --- | --- | ---: |
| `aiur-engine.sh` | setup, `die`, module sourcing, `usage`, `dispatch_run`, `aiur_engine_main` | ~300 |
| `engine/identity.sh` | identity, distribution, release resolution, argv | ~300 |
| `engine/oneshot.sh` | version, init, local CLI, logins, todo, findings, asks | ~180 |
| `engine/run.sh` | dotenv, run argv, `run_session` (split into named phases inside), attach, tmux conf | ~470 |
| `engine/processes.sh` | pid helpers, stale smoke inventory and reaping, agent and cwd reaping, watchdog | ~480 |
| `engine/instance.sh` | instance records, launch lock, crash markers and alerts | ~230 |
| `engine/control.sh` | liveness probes, control identity, RPC runner and dispatch | ~490 |
| `engine/commands.sh` | `cmd_status` … `cmd_set` | ~480 |
| `engine/executor_commands.sh` | `cmd_executor_*` verbs | ~330 |
| `engine/lifecycle.sh` | sweeps, `cmd_stop`, `cmd_restart`, `verify_restart_build` | ~460 |
| `engine/upgrade.sh` | upgrade notice and `cmd_upgrade` | ~220 |

- **Sourcing:** `aiur-engine.sh` resolves its own real directory once
  (`AIUR_ENGINE_DIR`, following symlinks with the same method the file already uses
  for its release root) and sources each module in a fixed order. A missing module is a
  `die` with the module path, not a silent skip. Sourcing keeps the `BASH_SOURCE`
  guard, so tests that `source` the engine still get all functions and no run.
- `run_session` (377 lines) is split into named functions in `engine/run.sh` (for
  example preflight, tmux layout, launch, wait). Each extracted function keeps its
  `local` variables and `trap`s in the same shell; no subshells are added.
- `package.json` `files` gains `libexec/engine/*.sh`. The engine test asserts the
  manifest lists every sourced module (new logic, so one test).

## Non-happy paths

- **Packaging gap:** a module missing from `files` works in a checkout and fails after
  `npm install`. The manifest test and the `npm pack` listing guard this.
- **Symlinked invocation:** `aiurdev` reaches the engine through a `PATH` symlink. The
  loader must resolve the real directory, or sourcing fails from another cwd.
- **`set -euo pipefail`:** sourced modules run under the same options. A module that
  references an unset variable at source time fails the whole launcher; modules define
  functions only, no top-level code.
- **Traps and cleanup:** `install_foreground_traps` and `session_cleanup` must run in
  the main shell; keep them as functions called from the same place.
- **Agent workspaces:** the `--test` block and identity isolation rules are behavior
  under test (`engine_control_test.exs:7`, shim tests). Do not change their order.
