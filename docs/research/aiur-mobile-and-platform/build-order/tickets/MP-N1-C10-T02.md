- **Bucket / feature / chunk:** 3 / MP-N1 / MP-N1-C10.

  and network changes behave as designed on real phones.
- **Deliverable:** results table per row × slot in the PR; failures filed with row IDs.

  transport rows (MP-N2-C10-T05).

DV-P8). Narrowest width: use the smallest-screen device available (record its CSS width).

## Implementation steps (procedures)

| Row | Steps | Pass | Required |
|---|---|---|---|
| DV-P6 | Open `/`, a worker `/chat/...`, `/commands`, `/build-orders` on the narrowest device and at 430 px width | No horizontal page scroll; native header covers no control; list any surface that should go native (surface-boundary §3) | Yes |
| DV-P7 | HTTPS origin: open a worker chat, press Dictate, allow mic once; speak a sentence. Then (only if the HTTP-degraded mode exists) repeat on an HTTP origin | HTTPS: one OS prompt, transcript returns. HTTP: mic shows `unavailable` with reason `insecure_context` | Yes |
| DV-P8 | Phone A and Phone B (or phone + dashboard) answer the same Command within 1 s | Exactly one answer recorded; the loser sees the winner's summary; no duplicate delivery to the agent | Yes if Phone-B exists |
| DV-P9 | (a) Restart the instance (new `secret_key_base`) while its WebView is open; (b) `aiur mobile revoke <device_id>` from the machine | (a) one silent re-bootstrap, page returns without prompt; (b) machine disappears after one notice; debug "Key state" shows no key/token for it; WebView cookies cleared | Yes |
| DV-P10 | Start an answer on Wi-Fi; switch Wi-Fi off mid-request (cellular + tailnet up) | Idempotent retry yields exactly one recorded answer (check the Command's history on the dashboard) | Yes |
| DV-P13 | Background the app 8 h with two instances paired | No background activity beyond pushes (iOS Settings › Battery; Android `adb shell dumpsys batterystats --charged <package>`) | Advisory |
