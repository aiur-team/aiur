- The controller parts are factories that take the shared mutable state object and
  return the handlers; `createPhysicalController` wires them. State stays one object,
  so ordering between handlers does not change.
- `channel-types.ts` re-exported from `channel.ts`, so importers keep their paths.

## Non-happy paths

- **Closure state:** inner functions read and write closure variables. When a part
  moves out, pass one state object; never copy a primitive, or two handlers see
  different values.
- **Real device:** HID report buffering (`MAX_BUFFERED_REPORTS`) and timeouts stay in one
  module. A device test is needed because unit tests fake the HID layer.
- **Coverage gate:** `vitest --coverage` thresholds, if configured, must still pass; do
  not add exclusions.
