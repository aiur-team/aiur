## Non-happy paths

- **Mixed broker versions:** daemon and workspaces now run the same embedded bytes,
  which is the #2307 goal; `LEDGER_VERSION` refusal stays unchanged.
- **State dir not writable:** `install!/1` uses `ensure_state_dir/1` and fails the
  same way an unwritable ledger fails today (broker unavailable, fail open per
  "a box without python3 fails open to :bypass"). Test it.
- **Concurrent install:** several callers may install at once; write to a temp file
  and `rename` (atomic), as `AgentGitHubGuard.atomic_install` does.
- **SQLite migration races:** `_add_column` comment (197–210) documents a real race;
  move the code and comment together, unchanged.
