## Implementation steps

1. Create `website/src/sim/` modules by moving functions unchanged; add `export`
   only where another new module needs it. `dashboard.ts` re-exports
   `buildDashboardLines`, `buildOpencodeLines`, `DASH_BOX_W`, `DASH_BOX_W_ABBR`,
   `OC_PANE_W`.
2. Run `npm run typecheck` and `npm run assert`.
3. Split the stylesheet into `website/src/styles/*.css` by section. Make
   `styles.css` a list of `@import "./styles/<part>.css";` in the original order.
4. `scripts/shot.ts`: replace the single `readFileSync` with a read of the five
   parts in the same order (one array of names). Keep the result one string.
5. Update `website/AGENTS.md:43` to name `src/sim/` and `src/styles/`.

## Non-happy paths

- **`@import` not inlined:** Vite inlines CSS `@import` in build. `shot.ts` does not;
  step 4 covers it. If any other reader inlines `styles.css` raw, it renders unstyled —
  grep `styles.css` again at start.
- **Docs app:** `website/docs-app/.vitepress/theme/custom.css:85` refers to the
  `.wordmark` rule only in a comment. Update the comment path if the rule moves.
- **Circular imports** between `sim/` modules: keep the direction
  geometry → segments → box/pane → dashboard.
- Netlify build (`website/netlify.toml`) runs `npm run build`; no path change there.
