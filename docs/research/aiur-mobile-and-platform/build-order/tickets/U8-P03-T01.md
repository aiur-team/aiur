- Bucket 1, unit U8 (file-size debt), package `ANALYTICS`, chunk `U8-P03`.

## Chosen design

| PROPOSED path | Takes | Est. lines |
| --- | --- | ---: |
| `analytics/lib/analytics/parse.py` | `parse_file`, `parse_line`, `_parse_timestamp` | 100 |
| `analytics/lib/analytics/reduce_actors.py` | actors and resource helpers | 150 |
| `analytics/lib/analytics/reduce_tickets.py` | tickets, intervals, review findings | 290 |
| `analytics/lib/analytics/materialize.py` | run/build summary writers, `_rollup_build`, `_atomic_write` | 140 |
| `analytics/lib/analytics/reduce.py` | `reduce_files`, `boot_summary`, record helpers, re-exports of moved public names | 300 |
| `analytics/lib/analytics/render_build.py` | build-report rendering | 140 |
| `analytics/lib/analytics/render.py` | aggregation and run-summary rendering | 390 |
| `analytics/scripts/regen_elixir_fixtures.py` (PROPOSED) | reduces the session fixtures, writes the two JSON fixtures with `source_files` relative to the repo, one record per line | 60 |

`reduce.py` re-exports `parse_file`, `parse_line`, `write_run_summary`,
`write_all_run_summaries` and `build_summary_for` so `reducer.<name>` callers keep working.

Fixture layout: valid JSON, top-level keys on their own lines, each list element on one
line (`json.dumps(x, sort_keys=True, separators=(",", ":"))` per element). `generated_at`
uses a fixed value passed as `opts["now"]`, so output is stable.
