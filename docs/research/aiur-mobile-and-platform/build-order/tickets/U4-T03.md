# U4-T03 - Backend stop and startup-diagnostic safety

## Identity and outcome

- Bucket 1, prior unit U4.
- **User value:** stopping a Claude worker leaves no orphan child processes;
  a short secret wrapped in colour codes cannot leak into the startup-failure
  log; that log cannot grow without bound.
- **Deliverable:** Claude `stop_port` kills the process tree before closing,
  using the same helper Codex uses; `StartupFailure.redact_line/1` strips ANSI
  before matching; the startup-failure file keeps at most the last N records.
- **Non-goals:** no shared backend base module (only identical safety logic is
  shared - plan U4 goal); no Muse change unless the same defect is found there
  (check `muse/session.ex` stop path and record the result).

## Dependencies and blockers

- U0-T01 only. **Decision:** the plan lists U2 as U4's predecessor; this
  ticket touches no lifecycle file, so it does not wait for U2.
- Must land before MP-R1-C5-T02 (moves process-signalling helpers to kernel)
  and MP-R7-C4-T04 (moves the adapters) - see edges.

## Verified starting point (`58854d4c8`)

- Codex: `codex/app_server_port.ex:174-195` `stop_port` kills the tree, then
  `Port.close`. Claude: private `stop_port` in `claude/coding_agent.ex:450-470`
  unregisters and closes, **never kills the tree**. #3034 and #3039 touched
  both without merging the code.
- `codex/startup_failure.ex` (#2895): file mode 0600 (:39-41); excerpts ≤ 4
  lines, 250 chars (:12, :56-63); file `<log_root>/<repo>.<ticket>.startup-failures.ndjson`
  opened in append mode (:18, :37), **never rotated or pruned**.
- `redact_line/1` (:76-84) keyword regex (:79); ANSI is stripped only at the
  start of a line for frame detection (:70). By source reading, `to\e[0mken=abc123`
  misses the keyword, and a value < 40 chars misses the long-value rule (:83).
  **Not reproduced** - the test below decides.
- `Aiur.SecretRedactor` (`secret_redactor.ex:11-21`) matches token prefixes; not
  used by `StartupFailure`.
- Tests: `startup_failure_test.exs:48, 54`.

## Chosen design

- Claude: call the same tree-kill used in `app_server_port.ex` (reference the
  function; do not copy it) before `Port.close`.
- Redaction: strip all ANSI CSI sequences from the line first, then apply the
  existing keyword and long-value rules. Also run `Aiur.SecretRedactor` on the
  stripped line (reuse, one call).
- Bound: before appending, if the file has ≥ 50 records, rewrite it with the
  last 49 (records are small; ponytail: rewrite is fine at this size - note
  the limit in a `ponytail:` comment).

## Implementation steps

1. Write the ANSI witness test first; run it - if it passes on unchanged code,
   record "bypass does not reproduce" and keep the strip only if another test
   needs it (do not ship an unproven fix).
2. Redaction change; bound; Claude stop.
3. Tests; Muse check.

## Non-happy paths

- **Tree kill fails (process gone):** ignore `:esrch`, as Codex does.
- **Rewrite fails mid-way:** write to a temp file and rename; on error keep the
  old file and append as today (never lose the newest record).
- **Remote/uncontained path** (`app_server_port.ex:143-150` closes with no
  kill): unchanged - there is no local tree.

## Compatibility and rollout

No config. Log file content shrinks to the last 50 records.
