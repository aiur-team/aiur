## Non-happy paths

- **Trust boundary in event history:** `maybe_atomize_digest_source/1` (`:266-272`)
  rehydrates only a fixed vocabulary, so an unknown source never becomes a trusted
  atom. Move the clauses unchanged, with the comment. `String.to_atom` must not appear
  in moved code.
- **Bounded transcript and edit payloads:** `bounded_transcript`,
  `bounded_edit_payload` and `json_safe` cap sizes and strip non-JSON data. Keep the
  caps in one place (`Encoding`).
- **Sanitizers:** `Projection.Sanitize` and `RecentMerge` `unsafe_control_chars`
  remove control characters from untrusted GitHub text. Do not change the patterns.
- **Writer restart:** `subscribe_agent/1` is idempotent on restart (`:410-416`); it
  stays in `IssueLog`.
- **`__MODULE__` in moved code:** `IssueLog` child spec and `via/1` use `__MODULE__`.
  If `via/1` moves, write the registry name and key with the literal `Aiur.IssueLog`,
  or a running writer is not found.
