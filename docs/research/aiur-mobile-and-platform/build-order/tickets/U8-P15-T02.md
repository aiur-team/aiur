## Non-happy paths

- **Real state:** init tests write `.aiur/` and `.env` files and may read `~/.aiur`. Each
  new file must keep the tmp-dir and `HOME` isolation of its source setup. A test that
  loses its isolation reads the operator's real config.
- **async:** keep each moved test's `async` value; init tests that change env vars must
  stay `async: false`.
