## Non-happy paths

- **Load order:** `Code.require_file` order matters; a delegate to a module not yet
  compiled fails at compile time of the test helper. Step 1 orders the requires.
- **Ignore filters:** a new `.exs` under `test/support/` that is not in
  `test_ignore_filters` makes `mix test` warn that it does not match the test
  pattern. Step 1 adds them.
- **Macros:** `receive_barrier/1` and `__using__/1` are macros; they stay in
  `Aiur.TestSupport` (a `defdelegate` cannot forward a macro).
- **Shared global state:** `reset_global_state!/0`, `capture_app_env` and
  `restore_app_env` stay together so restore always pairs with capture.
- **Reset safety:** the agent-workspace guard (`:79`, tests `:219-276`) must still
  abort before any GitHub call. The split adds no call path that skips `run/1`.
- **Real state:** tests here must keep temp `HOME` and temp dirs; no test reads
  `~/.aiur` (AGENTS.md).

## Compatibility and rollout

No config change. `mix aiur.test.reset` interface and output are unchanged. Test
modules that call `Aiur.TestSupport.<fun>` by full name keep working via delegates.
Rollback is a revert of each PR.
