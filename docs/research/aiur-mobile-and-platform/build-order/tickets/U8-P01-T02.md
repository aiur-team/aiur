# U8-P01-T02 — Split agent environment, process log, model discovery and accounts

## Identity and outcome

- Bucket 1, unit U8 (file-size debt), package `AGENT_CORE`, chunk `U8-P01`.
- **User value:** none visible. It removes size debt from five agent-identity modules and
  their tests, so each responsibility can be read and reviewed alone.
- **Deliverable:** `Aiur.AgentEnvironment`, `Aiur.AgentProcessLog`, `Aiur.ModelDiscovery`,
  `Aiur.ModelAvailability` and `Aiur.Accounts` each become at most 500 lines with the same
  public API. Their internals move to named submodules. Four test files split by `describe`
  group or by concern.
- **Non-goals:** no change to environment scrubbing, sweep cadence, discovery cache format
  (`model-usage.json`, the discovery cache file), account registry layout or session-move
  semantics.

Rationale: each new module is one responsibility that already sits as a contiguous block.
Pure predicates (`Limits`, `PriceDrift`) become unit-testable without file IO. Invariants:
the `:persistent_term` key `{Aiur.ModelDiscovery, :memo}` keeps its exact value, so a hot
reload or a test that erases it still works; `AgentProcessLog` keeps its registered name
and child spec; file paths and JSON layouts do not change.

Tests: `agent_environment_test.exs` → `agent_environment/shell_scrub_test.exs` (:1-:531 cases)
and `agent_environment/workspace_env_test.exs` (the four describes). `agent_log_test.exs` →
keep path/read describes; move `parse/1` into `agent_log/parse_test.exs`, which may split by
event family if it stays over 500. `model_discovery_test.exs` → `model_discovery/sources_test.exs`
(:23-:292) and the rest. `accounts_test.exs` → `accounts/session_move_test.exs` (:493-).

## Non-happy paths

- `AgentEnvironment` scrubs credentials from agent processes (AGENTS.md "Agent processes do
  not inherit GITHUB_TOKEN"). The move must not drop a name from any scrub list. Compare
  `provider_credential_env_names/0` and `app_credential_env_names/0` output before and after.
- `Accounts.move_session/6` has rollback on partial failure (`rollback_renames`,
  `rollback_copies`, `rollback_transfer`). Keep every `with`/`else` branch; the existing
  rollback tests (:594, :619, :560) must stay green.
- `ModelDiscovery` refresh uses a lock id and bounded timeout; keep the lock and the
  `contained_refresh` crash isolation in the same module as `refresh/2`.
- Tests touch HOME-relative account paths; keep the per-test `home` tmp setup in each new
  file.
