## Non-happy paths

- **Ordering and cursor redelivery:** "cursor redelivery defense", "stall retry and
  dead-letter" and "restart restoration" guard delivery order; the GenServer keeps the
  mailbox, so moved pure code cannot reorder.
- **Untrusted output:** `scrub_untrusted_output/1` removes untrusted command fields
  before an event reaches the Executor. It must stay on the publish path, unchanged.
- **Wake journal durability:** journal appends happen before acknowledgement; the
  journal module keeps write-then-advance order. Torn or corrupt pending files keep
  their tagged-error handling.
- **Sounds in tests:** `_test_env_without_player_override?` prevents playing sounds in
  tests; keep it with the player code.
