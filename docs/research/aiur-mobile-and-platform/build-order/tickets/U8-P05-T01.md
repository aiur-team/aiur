## Chosen design

Part (a), under decision option 1:
- Delete the three HTML files. In `design-manifest.md` replace each path cell with a
  permalink `https://github.com/aiur-team/aiur/blob/<sha>/docs/build-order/prototype/<file>`
  at the last commit that holds it, and keep the SHA-256. Update the citing lines to the
  permalink. `prototype/README.md`, `feature-constraints.md` and assets stay.

Part (b):
| PROPOSED path | Takes | Est. lines |
| --- | --- | ---: |
| `docs/build-order/EXECUTOR-HANDOFF.md` | first `##` section unchanged (seed for `Executor.Handoff`), `---`, then an index table: section title, date, archive link with anchor | 200 |
| `docs/build-order/executor-handoff/YYYY-MM-DD-<slug>.md` | one dated checkpoint each; large ones split at their `###` headings | ≤ 500 each |
| `docs/build-order/executor-handoff/standing-contract.md` | `## Start gate` … `## Adjacent delivery` | 300 |
| `docs/build-order/AGENT-CHAT.md` | header :1-:14 and an index of entries | 120 |
| `docs/build-order/agent-chat/YYYY-MM-DD.md` | one file per day of entries | ≤ 500 each |

Replace the Tailscale address with `<dashboard-host>` in every moved line. Keep every
heading text, so heading anchors in the new files match the old fragment names.

  break. Search inbound references: `git grep -n "EXECUTOR-HANDOFF.md#\|AGENT-CHAT.md#"`.
- If the decision is option 2 or 3, part (a) changes; do not delete before the decision.
