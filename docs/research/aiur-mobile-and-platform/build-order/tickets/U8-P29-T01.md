## Non-happy paths

- **Hidden ordering coupling:** the suite is synchronous, so tests may rely on global
  `Application` env set by an earlier test. Run each new file alone and the whole
  directory with `--seed 0` and two random seeds. A failure in isolation is a
  pre-existing ordering bug: fix the setup in the moved test (add the missing
  `put_env`/`on_exit`), and say so in the PR.
- **Module name collisions:** fakes registered by name in `Application` env
  (`:ci_watcher_*` keys) are referenced as module atoms. `git grep` every fake name
  under `src/test` before renaming; no other suite may refer to the old nested names.
- **Python helper:** the shutdown block (`:6800-6907`) embeds a Python script
  (`import os` at `:6889`). Move it byte for byte.
- **Coverage:** no production module changes, so the 85% `test_coverage` threshold in
  `src/mix.exs` is unaffected.
