## 1. Identity and outcome

  filters, feature header, usage strip).
- **User value.** The two cards above the board ("APIs" and "Models") show the
  real provider windows, accounts, credits and GitHub budget, with the design's
  look, hover popover and layouts. A value Aiur does not know is shown as
  unknown, never as `0%`, an empty track or a frozen countdown. A locked session
  sees a locked message and no values.

  1. PROPOSED `src/priv/static/build-home/usage.js`: the port of `PSETS`-shape
     rendering (`tone`, `avg`, `bar`, `tipA`, `ln`, `whoH`, `winTip`, `prow`,

     `hook.js` (rule 2).

     `src/priv/static/build-home/home.css` (C2-T03 creates it, C2-T04 fills it)
     in one marked block.
  4. Test-only fixture support: usage blocks for the n2 and n7 layouts and for
     each edge case, sent as a `set.usage` diff by a PROPOSED fixture-server

- **Non-goals.**
  - No data mapping, no presenter, no polling, no `UsageWatch` element (C8-T02).
  - No payload schema or validator change (C3-T02). This ticket renders only what
    the validator accepts.
  - No models counter cycling (OQ-E8-8 default) and no `?models=` URL key
    (C3-T03 drops it).
  - No focus-ring look (S-12, C12-T05) and no phone-width redesign (C12-T04).
    This ticket proves the design's own container breakpoints (C:806–807).

## 4. Chosen design

### 4.1 Input

`ctx.snap.usage` (C3-T02 schema v1, extended by C8-T02 §4.6). `intake()` does not
copy `usage` into `ctx.D`, so the renderer reads the payload-form snapshot.

```text
usage = { state: "authorized", observed_at: ms|null, apis: [prow], providers: [prow] }
      | { state: "locked", accessible_name, reason, authentication_path }
      | { state: "unavailable", observed_at: ms|null, reason }
prow  = { name, logo|null, mono|null, hue|null, icon|null, accounts|null,
          session: win|null, weekly: win|null, credits|null, none: bool,
          lines: [line]|null, stale: bool, observed_at: ms|null, note: str|null }
credits = { pct: int|null, left: str, tip: [[str,str]] }   // left may be "unknown" (C8-T02 §4.3)
win   = { acc: [int|null], reset_at: ms|null, win: str|null }
line  = { tag, acc: [int|null], reset_at, win, tip: [[str,str]], hold_until: ms|null }
```

The three `usage` states and the base `prow` are C3-T02's (`MP-E8-C3-T02.md:306-308`,
`:340-345`). `icon`, `lines`, `stale`, `observed_at`, `note`, `hold_until` and
`win.win: null` are C8-T02's §4.6 fields, listed in C3-T02's "Accepted additive
fields" table and added by C8-T02 (R-G1). C3-T02's `prow.tag` is not read: tags live on `lines`.

**Row kind** (checked in this order): `lines` → one `ln` per line (API rows);
`credits` → the credits line; `none` → the "not observed" line; else the session
then weekly line, skipping a `null` window. A row with no `lines`, no `credits`,
`none: false` and both windows `null` renders as a `none` row with the note
"not observed" (it never renders an empty `.ax-lns`).

`ctx.snap === null` (before the first payload): `renderUsage` does nothing, so the
empty dead-render host stays (EC-01, no flash).

### 4.2 Rendering rules (port first, change only what real data needs)

Each design function is copied and changed only as listed:

| Design | Product change | Reason |
| --- | --- | --- |
| `PSETS[S.models]` | `u.providers` | real data |
| `"2 APIs"` literal | `n + (n === 1 ? " API" : " APIs")`, `n = u.apis.length` | real count |
| `button.ax-cnt#ax-cnt` "N models" + click | `<span class="ax-cnt" id="ax-cnt">` with `n + (n === 1 ? " model" : " models")`, no handler, no title, no `tabindex` | OQ-E8-8 default |
| `avg(acc)` | mean of the integers only, rounded; `null` when none is an integer | `avg` adds `null` as `0` |
| `bar(acc)` | a `null` slot renders `<span class="ax-seg none"></span>` (no `<i>`) | unknown is not an empty track |
| `ln` reset | `reset = fmtLeft(reset_at - nowMs())`; see §4.3 | data has times, not strings |
| `ln` `tag`, `win`; credits `left` | through `esc` (J:1016–1017, J:1023 interpolate raw) | payload strings |
| credits `left === "unknown"` | right side `<span class="ax-no">unknown</span>` instead of `<b class="ax-usd">` | C8-T02 sends `"unknown"`; a green money style would read as a value |
| `winTip` | a `null` slot prints `"not observed"`, never `"null%"` or `"0%"` | EC-08 |
| `whoH` `<b>` | `esc(p.name)`; `.ax-mono` text `esc(p.mono ?? first letter of p.name, uppercased)`; hue only when `Number.isFinite(p.hue)` | J:1018 raw interpolation; a row with no `mono` never shows an empty circle |
| `p.icon` (SVG string) | `p.icon` is a key into a frozen null-prototype table `{ github: I.github, bars: I.bars }`; any other value → the `.ax-mono` letter | payload carries keys, not markup; `bars` is needed for the design-fixture Search row (parity) |
| `p.logo` (URL) | `LOGOS[p.logo]` → `src` and `fill` (C2-T03); missing key → `.ax-mono` (S-13) | payload carries keys |
| GitHub/Search literals | each `prow.lines` entry renders through `ln` with its `tag` and `tip` | real lines |
| `none` rows | rows `[["Limits", p.note ?? "not reported by provider"]]` | C8-T02 sends the reason |

**Line heads** (the popover title) keep the design's words:
- session/weekly: `"<name> · resets in <reset>"`;
- credits: `"<name> · credits"`;
- API line: `"<name> <label> · resets in <reset>"`, `label` = `core` → `"core"`,
  `gql` → `"GraphQL"`, else the tag (J:1033–1034); with tag `credits` the head
  is `"<name> · renews in <reset>"`, with no label (J:1036 "Search · renews in
  22d").
- When `reset` is unknown or the window has ended (§4.3), every head drops the
  `" · resets in …"` / `" · renews in …"` part: `"<name>"` or `"<name> <label>"`.
  It never prints `"resets in "` with an empty or stale value.

**Order.** Rows in payload order (C8-T02 sorts them). Session line before weekly
line. API lines in payload order (`core` before `gql`).

**Layout class.** `n<providers.length>` and `lay-cols` when the length is `>= 7`,
else `lay-rows`, exactly J:1030. Only `.n2` has CSS of its own (C:797–800); other
counts (1, 3, 5, 6) use the generic rules, as the design's would.

### 4.3 Time labels

`fmtLeft(ms)`, from the design's strings (minutes floored; a negative `ms`, from
clock skew, is treated as `0`, so the output is never `"-1m"`):
- `ms < 3_600_000` → `"<m>m"` (`"58m"`, `"37m"`);
- `ms < 86_400_000` → `"<h>h <mm>m"`, minutes two digits (`"3h 02m"`,
  `"1h 27m"`);
- else `"<d>d <h>h"`, or `"<d>d"` when `h = 0` (`"6d 23h"`, `"22d"`).

States:
- `reset_at === null` or `nowMs() === null` → right side `<span class="ax-no">reset
  unknown</span>`, no `I.cycle`.
- `reset_at <= nowMs()` → right side `<span class="ax-no">window ended</span>`, and
  the line gets `.stale` (the value belongs to the old window; C8-T02 marks this on
  the server too, but the client clock passes it between pushes).
- `win === null` → no `<em>/win</em>`, as J:1017 already does.

**Tick.** `ctx.life.every(30_000, tick)`. `tick` re-runs `renderUsage()` only when
`!document.hidden` and at least one row or line has a `reset_at`, a `hold_until` or a stale `observed_at` (the age in the tip also moves).
`renderUsage` builds the HTML string first and writes it only when it differs
from the last string written, so an unchanged strip keeps its DOM (no popover
flicker, no work).

**Popover across a re-render.** Every `.ax-ln` has `data-k="<api|mdl>:<row>:<line>"`.
When the strip is rewritten while `.ax-pop.show`, the hook looks up the same
`data-k`; if it still exists it refills and repositions the popover from the new
line, else it hides it. A live update never leaves a popover with old values or
pointing at a removed node.

### 4.4 Popover

`wireUsagePop` verbatim, with three mechanical changes (C9-T01 rules 3 and 4):
- listeners through `ctx.life.on` (the scroll one as
  `ctx.life.on(window, "scroll", hide, { passive: true, capture: true })`);
- the 60 ms hide uses `ctx.life.later("ax-pop-hide", 60, hideIfOut)` instead of
  `setTimeout`/`clearTimeout(axT)`. `life.later` has no cancel, so the design's
  `clearTimeout` becomes a flag: `mouseover`/`focusin` set `axOver = line`,
  `mouseout`/`focusout` set `axOver = null` and schedule `hideIfOut`, which
  removes `.show` only when `axOver === null`. Same visible timing, and
  `dispose()` clears the timer;
- the `div.ax-pop` lives on `document.body`, outside the LiveView container
  (`MP-E8-C3-T01.md:176`). `createLife()` has no hook for a node cleanup
  (`MP-E8-C9-T01.md` `life.js`), so `onReset` runs `axPop?.remove()` and clears
  `axPop`, `axOver` and `lastHTML`, and the mount creates a fresh node. Between
  leaving `/build` and coming back, the old node may stay in `body`; it is
  `opacity: 0` and `pointer-events: none`, so it has no visible or input effect,
  and B9 proves there is exactly one after the return.

Extra rows the product appends after the server's `rows` (C8-T02 handoff to this
ticket):
- `stale` row or line: `["Observed", age(observed_at)]`, where `age` is
  `fmtLeft(nowMs() - observed_at) + " ago"`, or `"never"` when `observed_at` is
  `null`. The head gets `" · stale"`.
- line with `hold_until > nowMs()`: `["Held for", fmtLeft(hold_until - nowMs())]`.
- a `note` on a non-`none` row: `["Status", note]`.

**Keyboard and screen reader** (never cut accessibility). Each `.ax-ln` gets
`tabindex="0"`, `role="img"` (ARIA does not allow a name on a plain `div`, so
an `aria-label` alone is not reliably read; `img` also stops the reader from
reading the `%` and reset spans a second time) and `aria-label` = head plus rows
as plain text
(`"Claude · resets in 1h 27m. Max · work 1%. Pro · personal 3%."`). `focusin`
shows the popover for that line and `focusout` hides it with the same 60 ms rule.
No visible change at rest; the focus ring is C12-T05's (S-12).

### 4.5 Locked and unavailable

- `state: "locked"`: `<div class="ax-usage n0 lay-rows locked"><section
  class="ax-uc lock" role="status"><div class="ax-uh">Usage</div><p class="ax-no">
  <b>{accessible_name}.</b> {reason} {authentication_path}</p></section></div>`,
  the order of `provider_meters.ex:35-38`. The words come from the payload (C3-T02
  copies `locked_capability/0`), not from a literal in the client. All three
  strings escaped. No `.ax-ln`, no `%`, no `$` in the DOM.
- `state: "unavailable"`: the same card with `<b>Usage unavailable.</b>` and
  the reason in words (`usage_source_failed` → "The usage source failed."; any
  other value → "Reason unknown."). No values, no zero bars.
- `providers: []` (authorized, nothing to show): Models header `"0 models"` and
  one `<p class="ax-no">No providers configured</p>` in `.ax-rows2`.
- `apis: []`: same, `"0 APIs"` and "No APIs observed".

## 6. Non-happy paths

- **Unknown percent** (`acc: [null]`): `.ax-pc` empty, `.ax-seg.none`, tip "not
  observed". Never `0%`, never `<i class="z">` (EC-08, EC-25).
- **Partly known accounts** (`[null, 40]`): `pct` = mean of the known (`40`), one
  dashed and one filled segment, tip `["personal", "not observed"]`. The `×2` chip
  still counts both accounts.
- **Credits with unknown percent** (`credits.pct: null`): empty `.ax-pc`, dashed
  single segment, `$` amount kept. **Unknown amount** (`left: "unknown"`): right
  side `.ax-no` "unknown", never a green `.ax-usd`.
- **One window missing** (`weekly: null`): only the session line; **both
  missing** (and not `none`/`credits`/`lines`): the `none` line with "not
  observed", never an empty row.
- **Row without `mono`** and without a known logo or icon: the first letter of
  the name in `.ax-mono`, never an empty circle.
- **Unknown reset**, **ended window**, **unknown window length**: §4.3.
- **Stale row**: values kept but dimmed, age in the tip. Not hidden, not shown as
  fresh.
- **GitHub hold**: tip row "Held for …"; no other mark (C8-T02 decision 6).
- **Locked session** (EC-12 via C8-T02): §4.5. A diff that changes the block from
  authorized to locked removes every value node on the next render, and hides an
  open popover (its `data-k` no longer exists).
- **Unavailable block**: §4.5, cause named, no values.
- **Hostile text**: provider, account, note, `tag`, `win`, `mono` and credits
  `left` strings go through `esc` in `<b>`, `title`, `.ax-mono`, `.ax-tg`,
  `<em>`, `.ax-usd`, `aria-label` and the popover. `hue` is used only
  when it is a finite number (C3-T02 also rejects `"1);x"`). `logo`/`icon` are
  keys looked up in frozen tables, never URLs or markup from the payload.
- **Many providers** (7+): `lay-cols`, two columns of logos (C:797–800). 1, 3, 5
  or 6 providers: `lay-rows` with the generic rules.
- **Reconnect / resync**: `repaint()` calls `renderChrome()`, so the strip
  re-renders from the new snapshot. The string compare means no DOM change when
  the block is the same.
- **Hidden tab**: the tick does nothing; on the next visible tick the labels jump
  to the current time.
- **Navigation away and back**: `ctx.life.dispose()` clears the tick, the
  listeners and the body `.ax-pop`; `onReset` clears `lastHTML`, `axPop`, `axT`.
- **Touch**: as in the design, a tap fires `mouseover` and shows the popover;
  the next scroll hides it. No new touch behaviour (C12-T04 decides).

## 10. Decisions made without the owner

1. **Unknown percent looks like a dashed segment** (`.ax-seg.none`), reusing
   `.ax-bar.none`'s dashed border. The design has no unknown look for a bar slot;
   an empty track would read as 0 %.
2. **Mean of known values only.** The design's `avg` counts `null` as `0`. With
   one account unknown, the line shows the known account's value and the tip
   names the unknown one.
3. **"reset unknown" and "window ended"** as the right-side text, in the `.ax-no`
   style the design uses for "not observed".
4. **Stale rows are dimmed to 55 %** and carry their age in the tip. The design has
   only the whole-page `.stale` for an offline daemon.
5. **Locked and unavailable use one full-width card** titled "Usage", with the
   Units page's locked words. The design has no locked state.
6. **Counter is a `span`** with the button's box and look at rest, no pointer and
   no hover (OQ-E8-8 default "not clickable, same look").
7. **Counts use singular forms** ("1 API", "1 model"); the design only shows
   plural counts.
8. **Countdown refresh every 30 s** while visible. The design's labels are static
   because its clock is fixed.
9. **Lines are keyboard-focusable** with an `aria-label`, so the popover values
   are reachable without a mouse. No visible change at rest.
10. **Hold shows only in the tip** ("Held for 37m"), following C8-T02 decision 6.
11. **Unknown icon keys fall back to the mono letter,** like unknown logo keys
    (S-13). A row with no `mono` uses the first letter of its name.
12. **The icon table keeps `bars`** although C8-T02 sends no Search row: the
    design fixtures need it for parity, and it is two lines of the design's own
    table.
13. **Usage lines are `role="img"`** with an `aria-label`. C12-T05 may change the
    role in its keyboard and screen reader pass.
14. **Unknown credit amount** (`left: "unknown"`) uses the `.ax-no` style, not
    the green `.ax-usd` money style.
15. **A row with no window** renders the "not observed" line instead of an empty
    row.
