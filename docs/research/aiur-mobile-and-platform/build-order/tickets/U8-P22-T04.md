## Non-happy paths

- **Trust boundary:** `unsafe?`/`document_unsafe?`/`url_unsafe?` decide which reads
  are never cached. They move only if `classify` moves with them; keep the regexes
  byte-equal. "safety: kinds that are never cached" guards this.
- **Orphan worker:** the off-process guardian kills the HTTP worker when the caller
  dies or the deadline passes. Keep links and monitors in the same process roles
  (`transport_test.exs` and `regression/github_ingestion_test.exs` "connectivity
  backoff wiring" exercise it).
- **Unbounded bodies:** `bounded_response_collector` caps response size; keep it.
- **Metric key growth:** `Metrics.refused_shape/2` caps keys; `Shapes` must still
  pass the route template, not the raw URL.
