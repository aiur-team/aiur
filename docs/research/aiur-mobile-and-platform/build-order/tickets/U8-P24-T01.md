## Non-happy paths

- **Fail closed:** "ensure_preflight/1 — proving it still fails closed" and
  "allowed-contributor issues" must stay green with no assertion edits.
  `deny_ambiguous` stays the answer to an ambiguous timeline.
- **Incomplete timeline:** `invalidate_incomplete_timeline` must still drop a partial
  ladder; do not reorder `store_timeline` and the decision.
- **Team lookup failure:** degraded CODEOWNERS mode (`degraded_mode_trusted?`) keeps
  its behavior (U5 trust failure matrix covers it).
- **Orphan `gh auth token` processes:** `run_bounded_gh_auth_token` and
  `kill_os_process` kill the process tree on timeout. Move them together.
- **Secrets:** `normalize_secret` and token functions never log values; keep that.
