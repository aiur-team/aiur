# U4-T01 - Settle pause once

## Identity and outcome

- Bucket 1, prior unit U4. Acceptance example AE6.
- **User value:** a paused worker is contained no matter where the pause
  arrives (mid-turn, between turns, while waiting for an operator message), and
  a queued Executor message is kept and delivered once after resume.
- **Deliverable:** one private-module function (in `agent_runner/`) that does
  today's pause settlement (confirm containment, usage alert, consume/restore,
  pause log, `send_control_state`, wait); used by `turn_loop.ex:184` and
  `queue_drain.ex:716`, and by the two between-turn receives that skip
  confirmation today. Hard `:ok =` bookkeeping matches become best-effort.
- **Non-goals:** no change to pause semantics, grace (5000 ms) or the control API.

## Dependencies and blockers

- U0-T01. U2-T01 (touches `pause_resume.ex:249, 2438`; land first, then rebase).
- Plan: U4 consumes U3's event delivery only where used - not here.
- MP-R7-C1 characterization tests run in place; if they land first, keep them green.

## Chosen design

- Move the `turn_loop.ex:184-212` body into one function (keep it in
  `turn_loop.ex` as a public `settle_pause/…` used by `QueueDrain`; no new
  module). Both mid-turn sites call it. The two between-turn receives call it
  too, which adds the missing `PauseContainment.confirm`.
- Replace each `:ok =` bookkeeping match with `best_effort_queue_bookkeeping`
  (logs and continues, as `turn_loop.ex` already does). Keep any match whose
  failure must stop the worker - check each: if failure would lose a queued
  message, keep the crash and add a comment why.

## Implementation steps

1. Extract `settle_pause`; replace the two mid-turn copies.
2. Call it from `drain_operator_messages` and `wait_for_operator_message`.
3. Bookkeeping matches.
4. Tests; then the foreground check in Verification.

## Non-happy paths

- **Pause during operator wait with a queued message:** message stays queued
  (restore path), delivered after resume - the test covers it.
- **Containment confirm times out:** existing grace behaviour (escalation in
  `pause_containment.ex`) now applies on all paths - that is the fix.
- **Bookkeeping store unavailable:** logged, worker continues; the message is
  not dropped from the in-memory queue.
