# U8-P09-T01 — Split the build gate script, holder and Elixir wrapper

## Identity and outcome

- Bucket 1, unit U8 (file-size debt), package `BUILD_GATE`, chunk `U8-P09`.
- **User value:** none visible. The local build admission gate (the BASH_ENV hook that
  queues concurrent `mix` compile/test work) becomes reviewable by concern. Its failure
  modes freeze or starve agent builds, so reviewability matters.
- **Deliverable:** `src/priv/build_gate.bash`, `src/priv/build_gate_holder.py`,
  `src/lib/aiur/build_gate.ex` and `src/test/aiur/build_gate_test.exs` at most 500 lines each.
  The hook stays the single sourced entry point at the same path; it sources sibling part
  files from its own directory. The holder stays the single executed entry point and imports
  sibling modules.
- **Non-goals:** no change to lease, slot, phase-lock or retain semantics; no change to
  the `aiur_build_gate` log lines, exit status 125, environment variable names or file
  layout under the gate directory. This is the build gate, not the U0 size gate.

Sourcing: inside the guard, `_aiur_build_gate_dir=${BASH_SOURCE[0]%/*}` then
`. "$_aiur_build_gate_dir/build_gate/<part>.bash" || return 125` for each part, in a fixed
order. A missing part fails closed through `aiur_build_gate_fail missing_part <path>`, the
same failure contract as other gate errors.

Holder imports: `sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))` then
`from build_gate_holder_lib import process_tree, files`.

Tests: split `build_gate_test.exs` by the regions above into `build_gate/status_test.exs`,

## Non-happy paths

- `BASH_ENV` sourcing runs in every non-interactive shell. A syntax error in a part breaks
  every agent command. Run `bash -n` on every part in the test suite.
- `BASH_SOURCE[0]` under `BASH_ENV` points at the hook file; verify with a test that sources
  the hook from a different cwd.
- The hook must not leak helper variables into the agent shell; part files define only
  `aiur_build_gate_*` functions and the one `_aiur_build_gate_dir` variable, which is
  `unset` after sourcing.
- Release packaging: `mix release` copies `priv/` whole; confirm `priv/build_gate/` and
  `priv/build_gate_holder_lib/` are in the release (`ls _build/dev/rel/aiur/lib/aiur-*/priv`).
- Fail closed stays the rule: a gate error returns 125 and does not run Mix.
