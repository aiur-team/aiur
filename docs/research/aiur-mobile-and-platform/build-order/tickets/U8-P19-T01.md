## Non-happy paths

- **Read-only mode:** `dashboard_writable?` gates controls; keep the check in the event
  handler, not only in the component.
- **Auth:** channel `join/3` rejects unauthenticated sockets and voice requires
  `streamdeck_authenticated: true`; keep these clauses in `StreamdeckChannel` itself so
  a reader sees the gate at the entry point.
- **CSP / unknown asset:** a JS file not in the allowlist returns 404 and the hook fails
  silently in the browser. The browser spec catches it only if it runs; it must run in
  this PR's CI.
- **Dropped browser tests:** a split spec not listed in `test:streamdeck` never runs and
  CI stays green. Compare test counts.
- **Config raising:** the test "mounts even when Aiur.Config raises" guards the
  `kind/2` rescue; keep that rescue with mount.

## Compatibility and rollout

No config change. A new static file is served; rollback is a revert of the PR, which
also removes its route.
