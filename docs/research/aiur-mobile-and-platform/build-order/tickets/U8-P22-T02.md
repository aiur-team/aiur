## Non-happy paths

- **Port ownership:** `owned_port_command` and `terminate_port` must run in the
  caller process that opened the port. Moving them into a module is fine; moving them
  into another process is not. "caller death reaps a blocked broker process" guards it.
- **Fail open:** a box without `python3` returns `:bypass`; a malformed broker reply
  is a broker failure, not exhaustion. Keep these branches verbatim (tests at 142,
  149, 280, 319).
- **Token material:** `token_key/1` hashes tokens; the hash must not change, or the
  shared ledger loses history (test "one credential keeps its admission history…").
- **Request log size:** `rotate_request_log` bounds disk; keep the byte accounting.
