# U8-P00-T02 — Close the U8 ledger: recount, adopt residue and hand the universal gate to U9

## Identity and outcome

- Bucket 1, unit U8, cross-package chunk `U8-P00`.
- **User value:** one place proves that the size debt is gone, so U9 can switch the
  transitional gate to the universal 500/501 rule without a surprise.
- **Deliverable:** a recount of all tracked text on the merged head; every path above
  500 is either zero or owned by an open ticket listed here; the ledger closing note
  with net LOC by source, tests, docs and generated, moved and removed lines apart.
- **Non-goals:** no code split in this ticket. Residue goes back to its package
  ticket or a new U8 ticket; this ticket does not fix it itself.

  net +4,285 lines. The transitional gate is not installed yet on `main`.

## Chosen design

Re-run the README census at the merged head and diff it with `assignments.csv` plus
README "New rows". Classify each remaining path: (a) at most 500 — closed; (b) open
ticket exists — wait; (c) no ticket — new residue, file a U8 ticket in its package;
(d) lockfile class — closed only if U8-P00-T01 option A passed.

## Implementation steps

1. Run the census script on the merged head SHA (not ambient local `main`).
2. Produce `u8-close-<sha>.md` in the research ledger: counts, the residue list, net
   LOC by area, moved versus removed lines, and the per-ticket PR list.
3. File residue tickets; repeat after they merge until (b) and (c) are empty.
4. Tell U9 the head SHA where the census reports zero (or only approved lockfiles).

## Non-happy paths

- **New oversized file lands during the close:** the transitional gate should stop
  it; if it did not, that is a gate defect for U0, and the file is residue.
- **A cut (U7) deleted a path:** count it as removed lines, credited to U7, not U8.
- **Concurrent research-branch commits:** stage only the closing note; never reset.
