## Non-happy paths

- **Lost agent context:** see Dependencies. The rule text stays; only the recipe moves.
- **Checker false pass:** if the checker reads only the first page, keys on other pages
  look undocumented (fail) — or, if it is loosened wrongly, missing keys pass. The new
  checker test must fail when a key is removed from every page.
- **Dead anchors:** VitePress builds without failing on a missing anchor in some
  setups; use the docs build link check if configured, else `git grep` each anchor.

## Compatibility and rollout

Docs only; no behavior change. Rollback is a revert. The `lint` job runs the config
docs checker, so PR 1 must pass it.
