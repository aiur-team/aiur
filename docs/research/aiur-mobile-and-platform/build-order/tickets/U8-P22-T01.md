## Chosen design

Split by responsibility. The facade keeps every public name and its `@doc`.

| PROPOSED path | Takes | Est. lines |

| `github/resource_store.ex` (kept) | short moduledoc, `use GenServer`, public API (delegating), callbacks | 480 |
| `github/resource_store/types.ex` — `Aiur.GitHub.ResourceStore.Types` | `@resource_types`, `@order_sensitive_types`, `resource_types/0`, `order_sensitive?/1` | 140 |

- Invariants: the table stays `Aiur.GitHub.ResourceStore.Table`, created by the

## Non-happy paths

- **Concurrency:** writes run in the caller process on a public ETS table. Moving
  the CAS code must not add a GenServer call or change `:ets.select_replace/2` match
  specs. `concurrency_test.exs` (claim contention, concurrent writers) guards this.
- **Restart:** `init/1` creates the table before `load` finishes (comment at 1367).
  Keep the order. `persistence_test.exs` ("surviving restart", "degrading") guards it.
- **Unreadable file:** `log_unreadable` path must stay fail-open.
- **Membership serialization:** `MembershipAccess.run/3` relies on the table owner
  being the facade process. Do not start the table from a submodule process.
- **Atom safety:** `safe_atom`, `known_source_atom`, `resource_type_atom` decode
  untrusted file content; they move unchanged.

## Compatibility and rollout

No config change, no file-format change. The facade keeps all callers. Rollback is
a revert of each PR. Release: new files are under `src/lib`, so they ship in the
release without packaging change.
