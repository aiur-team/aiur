# U3-T02 - Claim ownership

## Identity and outcome

- Bucket 1, prior unit U3. Acceptance example AE3.
- **User value:** two Executor sessions never both act as owner; the old one
  is told it lost ownership instead of silently regaining it.
- **Deliverable:** `do_claim/3` demotes an expired owner on takeover;
  `do_renew/3` refuses when the caller is not the live owner and a rival is
  live; acknowledgement and revoke pick the owner deterministically.
- **Non-goals:** no lease length change; no new roles; no CLI change.

## Dependencies and blockers

- U0-T01. U3-T03 depends on this.

## Verified starting point (`58854d4c8`)

- `src/lib/aiur/executor/claims.ex` (485 lines): `do_claim/3` (:256-263)
  refuses only when another **live** owner exists; it does not demote an
  expired one. `do_renew/3` (:265-270) calls `touch(consumers, id,
  existing["role"], …)` with no liveness or rival check; `touch/5` (:309-325)
  gives a fresh `lease_expires_at`.
- Sequence A expires → B claims → A renews: **both A and B are live owners.**
  `prune/2` (:446-452) keeps A (only old entries are pruned).
  `do_record_acknowledgement/4` (:286-293) takes the first live owner from
  `Map.values` - either can win; `do_revoke` (:272-283) same.
- Lock seam: `mutate/3` (:351-363).
- Test `test/aiur/executor/claims_test.exs:28` covers takeover only.

## Chosen design

- `do_claim/3` takeover: set the expired owner's role to `"observer"` (the
  non-owner role the module already uses; check the exact string) in the same
  write. `mutate/3` today writes one entry (`{:ok, entry}`) or the whole map
  (`{:replace, map}` → reply `{:ok, :ok}`), and `claim/2` callers
  (`agent_control_cli.ex:486, 625, 716`) match `{:ok, entry}`. Add a
  `{:replace, consumers, reply_entry}` return to `mutate/3` and use it here.
- `do_renew/3`: guard **only** an owner-role entry whose lease is expired while
  another live owner exists → `{:error, :not_owner}`, no touch. Observer
  entries renew as today (`renew/2` is documented as role-preserving and
  observers use it).
- `renew_lease_forever` (`agent_control_cli.ex:504-507`) discards the renew
  result today; on `{:error, :not_owner}` it switches the wait loop to observer
  and prints the existing "not the owner" message.
- Ack/revoke: select the owner whose lease is live; if more than one (legacy
  file), pick the latest `claimed_at` and log once. Ties never depend on map order.

## Implementation steps

1. Claim demotion; renew guard; deterministic owner pick.
2. `mutate/3` reply shape; `renew_lease_forever` reaction.
3. Tests.

## Non-happy paths

- **Clock skew between sessions:** lease times come from the daemon clock in
  `mutate/3`, not the client; unchanged.
- **Legacy file with two live owners:** deterministic pick + one warning; the
  next claim cleans it.
- **Lock contention:** unchanged single-writer `mutate/3`.

## Compatibility and rollout

On-disk format unchanged (role string reused). Rollback: revert.
