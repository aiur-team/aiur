- `Codec` and `Reducers` are pure modules called only by their parent. The parent keeps
  every public function; nothing outside calls the private helpers today.
- `DecisionAttention.LegacyImport` returns messages the GenServer sends to itself;
  the timers stay owned by the GenServer.

## Non-happy paths

- **Unknown event types:** `from_json_safe/1` and the reducers keep their
  `Unrecognized` path (`decision_event/unrecognized.ex`). The "unrecognised event types"
  tests guard it; move those clauses with the dispatcher, not into a catch-all.
- **Corrupt records:** decode errors return tagged errors, never raise. Keep the
  `{:error, :not_a_map}` clauses with their public function.
- **Attention restart:** "startup import bounds projection fanout and restored timers"
  and "a live open wins over a delayed startup import" guard ordering; keep the import
  as messages through the GenServer mailbox.
