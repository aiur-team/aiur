## Non-happy paths

- **Receiver restart:** `terminate/2` must keep stopping the linked Bandit listener;
  keep it in the GenServer module. `application_test.exs` covers the child order; do
  not change the child spec.
- **Capability secrecy:** `format_status/1` redaction must still cover every key the
  extracted modules add to state. The test "status inspection redacts
  capability-bearing state" guards it.
- **Closed port:** `send_frame/2` swallowing `ArgumentError` stays unchanged; the two
  #708/#699 regression tests guard it.
- **Dynamic dispatch:** the turn loop calls backend callbacks by module. A missing
  `defdelegate` fails at runtime, not at compile time. The refusal tests and
  `coding_agent_claude_test.exs` exercise every callback.
- **Async tests:** the telemetry tests start a named server per test; keep their
  `async` setting unchanged when you move them.
