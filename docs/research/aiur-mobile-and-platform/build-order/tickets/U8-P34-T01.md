  take and return the same state; no new process.
- **Restart and retention order:** writer restart keeps boot identity and sequence
  (`writer_test.exs:319`). The retention move must keep the call order in `init/1`
  (prune before first append).
- **Fail-open paths:** writer failures never crash callers (`:293-304`, `:800`);
  sampler EACCES and exiting PIDs give one warning (`:363-395`). Keep every
  `rescue`/`catch` with the code it guards.
- **Async tests:** `writer_test.exs` is `async: false` (shared file paths). New
  writer test files keep `async: false`.
