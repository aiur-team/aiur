# MP-N2-C2-T03 — Safe `.instance` record parser

## Identity and outcome

- **Bucket / feature / chunk:** 3 / MP-N2 / MP-N2-C2.
- **User value:** the gateway can list instances (including crashed ones) from the launcher's
  records without ever executing them. The launcher `source`s these files; a second reader that did
  the same would turn a writable state dir into code execution in the gateway.
- **Deliverable:** `Aiur.Machine.InstanceRecord.parse(binary) :: {:ok, map} | {:error, reason}`
  (PROPOSED) and `list(dir) :: [{path, {:ok, map} | {:error, reason}}]`.
- **Non-goals:** writing records; changing the launcher's format.

## Dependencies and blockers

DESIGN-N2 gate only. Concurrent with everything in C1/C2/C3. Dependent: MP-N2-C2-T04.

## Verified starting point (base `45a290e3`)

- Writer: `write_aiur_instance_record` (`packaging/npm/aiur-cli/libexec/aiur-engine.sh:1586-1612`)
  emits `printf 'AIUR_RECORD_<NAME>=%q\n'` for NODE, INSTANCE_KEY, SESSION, SOCKET, AGENT_TMPFILE,
  SURFACE_MODE, WORKSPACE_ROOT_FILE, PROJECT_ROOT, PROJECT_ROOT_SOURCE, WRITTEN_AT, mode 0600.
  (The MP-N2 plan F3 lists the names without the `AIUR_RECORD_` prefix; the prefix is real.)
- Reader: `load_aiur_instance_record` `source`s the file (`:2174-2187`) and requires NODE, SESSION,
  SOCKET and PROJECT_ROOT non-empty (`:2188-2189`).
- `%q` is bash's shell-quoting format: plain safe characters unchanged, other characters
  backslash-escaped, and non-printable characters as `$'...'` ANSI-C strings — GNU Bash manual,
  "Bash Builtins → printf" (<https://www.gnu.org/software/bash/manual/bash.html#index-printf>,
  Bash 5.2/5.3 manual, accessed 2026-10-06).

## Chosen design

- Line grammar: `^AIUR_RECORD_([A-Z_]+)=(.*)$`. Keys outside the ten above are ignored (forward
  compatible). Lines that do not match are counted in `:ignored_lines`.
- Value decoding supports exactly two `%q` forms: (a) backslash-escaped text (`\X` → `X`), and
  (b) a whole-value `$'...'` with `\n \t \\ \' \xHH \NNN`. Anything else containing `$`, backticks,
  unescaped quotes or parentheses returns `{:error, {:unsupported_value, key}}` — the value is never
  evaluated or substituted.
- Required keys as the launcher requires them: NODE, SESSION, SOCKET, PROJECT_ROOT; missing →
  `{:error, :incomplete}`.
- Output map: `%{node, instance_key, session, socket, surface_mode, project_root, project_root_source,
  written_at}` (`agent_tmpfile` and `workspace_root_file` dropped: the gateway does not need them).
- Files larger than 16 KiB are rejected unread (`:too_large`).

## Implementation steps

1. `src/lib/aiur/machine/instance_record.ex` (PROPOSED). 2. Fixtures generated by running the real
`printf %q` in the test via `System.cmd("bash", ["-c", ...])` so the decoder is tested against the
real encoder. About 120 production lines.

## Non-happy paths

Malicious content (`$(touch …)`) → `:unsupported_value`, nothing executed. Unreadable file → `{:error, :eacces}`. Partial write (should not happen: launcher uses temp+mv) → `:incomplete`.

## Compatibility and rollout

Read-only. If U1/U9 change the record format, the fixture test fails loudly (that is the point).
