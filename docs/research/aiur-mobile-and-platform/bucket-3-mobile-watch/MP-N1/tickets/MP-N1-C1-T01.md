## Chosen design

- **Framework:** React Native on Expo with Continuous Native Generation (CNG): the
  `ios/` and `android/` folders are generated by `expo prebuild` and are **git-ignored**;
  all native configuration lives in `app.config.ts` and config plugins (framework-evidence §4).
- **Pins:** exact versions (no `^`) for `expo`, `react-native`, `react`,
  `react-native-webview`, `expo-dev-client`, `jest-expo`, `typescript`. Version values are the
  ones `npx create-expo-app --template blank-typescript` produces for the then-current SDK
  (SDK 57 at research time). A `docs/UPGRADING.md` inside the package (PROPOSED) holds the
  upgrade-note template: SDK from→to, RN from→to, breaking notes read, prebuild diff
  reviewed, device rows re-run.
- **Test runner:** Jest with `jest-expo` (the Expo-supported preset). Vitest is the
  Stream Deck's runner but does not transform React Native modules; consistency loses to
  support here.
- **Identifiers (PROPOSED, DESIGN-N1 D-N1-4 may change them):** iOS bundle id and Android
  application id `dev.aiur.mobile`; the watch targets later reuse it (RC-17).
- **Layout** (PROPOSED, matches plan.md §3.1): `app.config.ts`, `src/App.tsx`,
  `src/shell/`, `src/screens/`, `src/capability/`, `src/api/`, `test/`, `fixtures/`.

## Implementation steps

1. `npx create-expo-app@<pinned> packages/aiur-mobile --template blank-typescript`; then
   remove generated sample assets and set `"private": true`, `"name": "@aiur/mobile"`.
2. Convert all dependency ranges to exact versions; commit `package-lock.json`.
3. `app.config.ts`: name, slug, `ios.bundleIdentifier`, `android.package`,
   `ios.deploymentTarget` via `expo-build-properties` (`ios.deploymentTarget: "17.0"`,
   `android.minSdkVersion: 29`, `android.targetSdkVersion` = SDK default),
   `newArchEnabled: true`.
4. `tsconfig.json` extends `expo/tsconfig.base` with `"strict": true`,
   `"noUncheckedIndexedAccess": true`, and `paths` `@aiur/contracts` → contracts package
   (or stub).
5. ESLint flat config mirroring `packages/streamdeck/eslint.config.mjs` plus
   `eslint-plugin-react-hooks`.
6. `.gitignore`: `ios/`, `android/`, `.expo/`, `node_modules/`.
7. `src/App.tsx`: root component rendering `<Text testID="app-root">aiur</Text>`.
8. `test/App.test.tsx` (see Verification).
9. Scripts: `typecheck`, `lint`, `test`, `prebuild:check` (`expo prebuild --clean --no-install`
   for both platforms into a temp dir), `ios`, `android`.
10. `mise.toml` with `node = "24"` (Stream Deck parity).
11. Docs: new `website/docs-app/guide/mobile.md` (local build: prerequisites Xcode/Android
    Studio, `npm ci`, `npx expo prebuild`, `npx expo run:ios|android`; "the app is not yet
    published"), and a sidebar entry next to "Stream Deck" in `config.ts:137-140`.

## Non-happy paths

- **Contracts package missing** (MP-R1-C3-T6 not merged): stub path above; the
  `typecheck` script must still pass.
- **Prebuild drift:** generated folders are never committed, so a stale native folder cannot
  ship; `prebuild:check` fails loudly if a config plugin errors.
- **Privacy:** no telemetry SDK, no crash reporter, no analytics are added (none approved).
- n/a for concurrency, retries, auth: the skeleton performs no I/O.

## Compatibility and rollout

- New package; nothing in `src/` (Elixir) changes. No config keys, no CLI flags.
- Rollback: delete the directory and the guide page.
- Packaging: not published anywhere (distribution is MP-N1-C8).

## Verification

- **Automated:**
  - `test/App.test.tsx` → `renders the root placeholder`: renders `<App/>` with
    `@testing-library/react-native` and asserts `getByTestId("app-root")` has text `aiur`.
    Mutation: delete the `Text` in `App.tsx` → test fails.
  - `test/pins.test.ts` → `every runtime dependency is pinned exactly`: reads
    `package.json` and asserts no version in `dependencies`/`devDependencies` starts with
    `^` or `~`. Mutation: change one pin to `^x.y.z` → test fails.
- **Commands:**
  - `npm --prefix packages/aiur-mobile ci`
  - `npm --prefix packages/aiur-mobile run typecheck`
  - `npm --prefix packages/aiur-mobile run lint`
  - `npm --prefix packages/aiur-mobile test`
  - `npm --prefix packages/aiur-mobile run prebuild:check`
  - macOS only: `npx --prefix packages/aiur-mobile expo run:ios --configuration Debug`
  - Linux/macOS: `npx --prefix packages/aiur-mobile expo run:android --variant debug`
  - Docs: `env -C website/docs-app bun run build` (the docs-app build step of
    `.github/workflows/website.yml:51-54`); a dead sidebar link fails the build.
- **Manual:** the debug app launches on an iOS 17 simulator and an Android API 29 emulator and
  shows "aiur". No physical-device row applies yet.
