| `loose-2-02` | `AgentControlCLI.status/1` still obtains a fleet view then prints listener, wake, CODEOWNERS, supervision, CI, build and asks sections sequentially. `ExecutorWakeInbox.stats/1` and `CodeOwners.trust_snapshot/1` remain synchronous mailbox calls; `Asks.Store.with_lock/2` configures a 30-second SQLite busy timeout and an exclusive transaction. | `loose-4-04` | `ExecutorWakeInbox.init/1` still returns `{:stop, reason}` on journal-summary failure. The existing test deliberately refuses a corrupt *pending store*, which is a distinct authority path from an invalid wake-journal record. Its focused tests cover invalid input and event-key dedupe, not failed enqueue. | Inject a refused/timed-out enqueue and one failed comment provider while others succeed; assert the agent sees explicit incomplete-context state or is held for retry, and that replay remains deduplicated across restart. |
