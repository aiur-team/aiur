**Release interpretation:** both are source-supported P0 mechanisms in the clean candidate. The credential path needs a synthetic environment regression and a retained governed-`gh` test; the stop path needs a stubbed two-instance pidfile regression. Neither existing test establishes those guarantees. A fix should be verified on the eventual release commit, with the new tests failing when its production hunk is reverted. Publication impact is conditional on the OpenAI-compatible backend executing `exec_command` with a daemon GitHub credential, or on stopping one live instance while another has a matching recorded headless agent; neither population was counted here.
