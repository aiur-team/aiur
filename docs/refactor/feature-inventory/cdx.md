## Coding-agent registry & Codex backend (FI-CDX)
The Aiur.CodingAgent backend registry and routing layer (backend/model/effort/remote resolution, delivery-policy flags), per-issue session-handle persistence, and the full Codex app-server adapter: spawn/handshake/turn protocol, approvals, dynamic tools, transcript, event humanizer, and codex.* config.

- **FI-CDX-001 · Backend registry (backends/0)** [api] — One map registers backends codex/claude/claude-repl with adapter + transcript modules, can_interrupt, safe_checkpoints, remote_control, resumable, immediate_delivery, models, and efforts; all dispatch, delivery-policy queries, override-label seeding, and routing validation derive from this map, and each flag encodes a real protocol capability consumed elsewhere (AgentRunner, delivery policy, init wizard) (src/lib/aiur/coding_agent.ex:69-123). Tests: src/test/aiur/coding_agent_test.exs:144-229. Risk: medium.

This asymmetry is intentional and tested. Tests: src/test/aiur/coding_agent_test.exs:182-212. Risk: low.
