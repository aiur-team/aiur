## CLI & control surface (FI-CLI)
Every operator-facing entry point: the Elixir `Aiur.CLI` flag/subcommand parser, the shell launcher engine (packaging/npm/aiur-cli/libexec/aiur-engine.sh) with its run modes and instance identity, the `AgentControlCLI` control-plane RPC subcommands, lifecycle/cleanup commands, the dashboard HTTP server startup gates, and the `aiurdev` dev shim.

- **FI-CLI-001 · Guardrails acknowledgement gate** [cli-flag] — Every run form requires `--i-understand-that-this-will-be-running-without-the-usual-guardrails`; without it evaluate/1 returns a red ANSI box-drawn banner (4 fixed lines, asserted verbatim) with ZERO side effects (no file check, no app env writes, no app start), printed to stderr with exit 1. The engine auto-injects the flag on run paths so bare `aiur` still works (src/lib/aiur/cli.ex:8,185-224; packaging/npm/aiur-cli/libexec/aiur-engine.sh:381,391). Tests: src/test/aiur/cli_test.exs. Risk: low.
- **FI-CLI-002 · aiur --version** [cli-flag] — Prints `aiur <version> (aiur-team/aiur <git-rev>)` where the short git rev is embedded at COMPILE time (empty if git fails); bypasses the guardrails gate and app start, matching only when `[version: true]` is the sole parsed option. The engine boots it distribution-free (no --name/--cookie) so it never collides with a running node (src/lib/aiur/cli.ex:10-16,45-46,96-97; packaging/npm/aiur-cli/libexec/aiur-engine.sh:288-298,2027-2029). Tests: src/test/aiur_engine_test.exs:120 (no unit test on output). Risk: medium.
- **FI-CLI-003 · aiur init** [cli-command] — Routes to the interactive setup wizard Aiur.Init.run/1 scaffolding .aiur/config (also writes ./.env — GITHUB_TOKEN etc. — which run_session later autoloads); no guardrails flag needed; extra positionals rejected with usage; init errors print to stderr and exit 1 via Aiur.Shutdown.shutdown(1). The engine boots init interactively and distribution-free so prompts receive keystrokes (src/lib/aiur/cli.ex:48-56,99-104; packaging/npm/aiur-cli/libexec/aiur-engine.sh:302-309,2030-2032). Tests: src/test/aiur/cli_test.exs:197-207, src/test/aiur/init_test.exs, src/test/aiur_engine_test.exs:253. Risk: medium.
- **FI-CLI-004 · init --force** [cli-flag] — Passes force: true to the wizard (overwrite an existing scaffold); aiurdev explicitly forwards --force to the engine rather than consuming it (src/lib/aiur/cli.ex:101; scripts/aiurdev:307). Tests: src/test/aiur/cli_test.exs:201, src/test/scripts_aiurdev_test.exs:384. Risk: low.
- **FI-CLI-005 · Positional config path + default discovery** [cli-command] — With no positional, runs Aiur.Workflow.detect_run_folder_config() (.aiur/config convention); an explicit positional is Path.expand'ed and must be a regular file, else 'Config file not found: <path>. Run `aiur init` to scaffold a .aiur/config.' Engine-side, a positional that exists on disk dispatches a foreground run; a non-existent word is 'unknown command' exit 64 (src/lib/aiur/cli.ex:106-150; packaging/npm/aiur-cli/libexec/aiur-engine.sh:2083-2092). Tests: src/test/aiur/cli_test.exs:62,77,155,210. Risk: medium.

- **FI-CLI-013 · AIUR_ARGV_FILE argv round-trip** [api] — System.argv() is empty under `elixir --eval`, so all wrappers write argv one-arg-per-line to a tempfile and export AIUR_ARGV_FILE; Aiur.CLI.argv_from_file/0 reads it back dropping empty lines ([] when unset/unreadable), while escript callers passing argv directly keep working. - **FI-CLI-014 · Supervisor-monitored shutdown exit codes** [lifecycle] — After a successful start, main/1 monitors Aiur.Supervisor until DOWN: reason :normal → exit 0, anything else → exit 1; supervisor not running at all → 'Aiur supervisor is not running' on stderr, exit 1. The engine's BEAM-death watchdog partly distinguishes clean vs crash exits via these codes (src/lib/aiur/cli.ex:40-62,312-330). Tests: none. Risk: medium. Check: start aiur, `aiur stop`, confirm the foreground process exits 0; kill -9 the BEAM and confirm nonzero exit.
- **FI-CLI-015 · Bare foreground run** [cli-command] — Bare `aiur` (or `aiur <flags...>` / `aiur <existing-path>`) spawns the release in a fresh tmux session on an instance-keyed socket, waits for control-plane readiness, then attaches; teardown traps clean up on exit; injects --host 127.0.0.1, --interactive, and the guardrails ack unless already passed. Attach stderr is filtered of '[server exited]' noise without process substitution, and a foreground BEAM-death watchdog is armed before attach so a crashed BEAM cannot leave attach hung (packaging/npm/aiur-cli/libexec/aiur-engine.sh:340-607,2076-2082). Tests: src/test/aiur_engine_test.exs:712,876; packaging/npm/aiur-cli/test/launcher.test.mjs. Risk: high.

- **FI-CLI-029 · Control RPC exit-marker protocol + timeout** [api] — Every AgentControlCLI command prints a trailing `__AIUR_CONTROL_EXIT__:<code>` (0/1) on stdout; the shell runs commands via one-shot `bin/aiur rpc` and translates the marker into the process exit code (missing marker = error) — the ONLY success/failure channel for status/agents/watch/alerts/pause/resume/message/set, and the marker string is duplicated shell-side. A watchdog kills the rpc helper after AIUR_CONTROL_RPC_TIMEOUT_SECONDS (default 10; invalid/0 falls back to 10) returning 124; transport failures are classified via epmd probe — down node gets a friendly hint or crash-marker orphan guidance, up/unknown surfaces raw rpc output (src/lib/aiur/agent_control_cli.ex:8,704-707; packaging/npm/aiur-cli/libexec/aiur-engine.sh:1459-1465,1484-1605).
