## Claude backends (headless + REPL/RC) (FI-CLD)
Everything under `src/lib/aiur/claude/` plus its web/orchestrator touchpoints: the headless app-server backend ("claude"), the persistent REPL/Remote-Control backend ("claude-repl"), claude-hook ingestion, transcript extraction/tailing, and process-hygiene reaps.

- **FI-CLD-001 · Headless claude session spawn** [lifecycle] — start_session opens a Port running `bash -lc <claude.command>` (default `aiur-claude`) in the workspace with scrubbed shell env, line-buffered at 1MB, then performs the JSON-RPC 2.0 initialize (capabilities.experimentalApi=true, clientInfo aiur-orchestrator @ mix version) + `initialized` handshake before thread/start; a thread/start failure closes the port so no process leaks (src/lib/aiur/claude/coding_agent.ex:33-58,198-220,232-261). Routed as backend "claude" via Aiur.CodingAgent (src/lib/aiur/coding_agent.ex:85). Tests: src/test/aiur/claude/coding_agent_test.exs, src/test/aiur/coding_agent_claude_test.exs. Risk: medium.
- **FI-CLD-002 · Workspace cwd validation on headless spawn** [lifecycle] — start_session refuses the workspace root itself ({:invalid_workspace_cwd, :workspace_root, path}) and any path outside Config.workspace_root() ({:invalid_workspace_cwd, :outside_workspace_root, ...}) before opening the port (src/lib/aiur/claude/coding_agent.ex:180-196). Tests: src/test/aiur/coding_agent_claude_test.exs:25,30. Risk: low.
