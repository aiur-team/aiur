## Configuration & personalization (FI-CFG)
Everything an operator can set in `.aiur/config` (or legacy `.aiurconfig`): the schema/parse pipeline, every config option and its default/validation, env-var and file-pointer resolution, sandbox policy resolution, path derivation, and compile-time `config.exs` baselines.

- **FI-CFG-001 · Config file names (.aiur/config + legacy .aiurconfig)** [lifecycle] — Runtime config loads from `.aiur/config` or the legacy `.aiurconfig` name; error messages name the actual file in use via `basename(Workflow.workflow_file_path())` (src/lib/aiur/config.ex:2-5, src/lib/aiur/config.ex:537-539). Tests: src/test/aiur/core_test.exs:176-198. Risk: medium.
- **FI-CFG-002 · Config.settings / settings_uncached / settings! loading API** [api] — `settings/0` loads via the WorkflowStore cache, `settings_uncached/0` re-reads the file bypassing it, `settings!/0` raises ArgumentError with operator-formatted messages that suggest "Run `aiur init`" for a missing file and label missing prompt_file / hooks_file / prewarm base_build_file / parse errors / non-map front matter distinctly (src/lib/aiur/config.ex:32-59, src/lib/aiur/config.ex:505-539). Tests: src/test/aiur/core_test.exs:62-69, src/test/aiur/log_file_test.exs. Risk: medium.
- **FI-CFG-003 · Schema.parse pipeline (normalize keys, drop nils, changeset, finalize)** [api] — `Schema.parse/1` recursively stringifies keys, drops nil values (with one preserved exception, see FI-CFG-054), casts through nested Ecto changesets, then runs finalize_settings (env resolution + codex policy key normalization); failures return `{:error, {:invalid_workflow_config, msg}}` with comma-joined dotted-path errors like `agent.max_turns must be greater than 0` (src/lib/aiur/config/schema.ex:575-589, src/lib/aiur/config/schema.ex:871-916, src/lib/aiur/config/schema.ex:984-1016). Tests: src/test/aiur/workspace_and_config_test.exs, src/test/aiur/core_test.exs. Risk: medium.
- **FI-CFG-004 · empty_values: [] casting (empty strings are real values)** [other] — Every cast passes `empty_values: []`, so blank YAML strings are kept as values rather than treated as missing: `codex_approval_policy: ""` parses at schema level and only fails at codex_runtime_settings; `codex.command ""` fails min-length while `"   "` passes (src/lib/aiur/config/schema.ex:55, src/lib/aiur/config/schema.ex:813-814). Tests: src/test/aiur/core_test.exs:106-125, src/test/aiur/workspace_and_config_test.exs:1723-1730. Risk: medium.
- **FI-CFG-005 · StringOrMap custom Ecto type** [api] — `Aiur.Config.Schema.StringOrMap` accepts a binary or a map on cast/load/dump and errors otherwise; it types `agent.codex.approval_policy` so legacy map-shaped policies still parse at schema level (src/lib/aiur/config/schema.ex:14-38, src/lib/aiur/config/schema.ex:208). Tests: src/test/aiur/core_test.exs:43-142, src/test/aiur/opencode/config_test.exs:105. Risk: medium.
