## Tmux, panes & agent-list TUI (FI-TUI)
Everything between the BEAM and the operator's terminal: the Aiur.Tmux command bus, PaneManager slot/layout/pane lifecycle, the agent-list TUI (App/Input/Renderer), and the tmux conf plus Ctrl-key bridges.

- **FI-TUI-001 · Tmux shell-out command bus** [integration] — All tmux ops serialize through the Aiur.Tmux GenServer shelling out via System.cmd; every call prepends `-L $AIUR_TMUX_SOCKET` (read per-call so late env export works) and targets AIUR_TMUX_SESSION (fallback "aiur"); binary path cached in :persistent_term; callers hitting a dead/absent server get {:error, :no_tmux} or {:error, :timeout} instead of crashing — this catch is load-bearing for every caller's degradation path (src/lib/aiur/tmux.ex:20,33,790,908). Tests: src/test/aiur/tmux_test.exs. Risk: high.
- **FI-TUI-002 · command/3 whitespace splitting with quoted tokens** [api] — Tmux.command/3 splits the command string on whitespace but re-joins double-quoted spans into one argv token; values with spaces must be quoted or use the args-based helpers (set_pane_title, send_keys_literal) that bypass splitting (src/lib/aiur/tmux.ex:960,969). Tests: src/test/aiur/tmux_test.exs. Risk: medium.
- **FI-TUI-003 · Mock transport seam and control-mode protocol parsing** [api] — Tmux accepts transport: {:mock, pid}; outbound commands arrive as {:tmux_mock_out, cmd}, responses injected as %begin/%end/%error-framed chunks (%error → {:error, body}); 1s timeout → {:error, :no_mock_response}; nearly every PaneManager/Tmux test depends on this seam (src/lib/aiur/tmux.ex:777,802,931). Tests: src/test/aiur/tmux_test.exs, src/test/aiur/tmux/protocol_test.exs, src/test/aiur/pane_manager_test.exs. Risk: medium.
- **FI-TUI-004 · Dead-tmux-server log demotion** [other] — tmux exec failures whose stderr contains "no server running" log at debug instead of warning (else the 2s screen-grab tick floods the log after the user kills the server); return value unchanged (src/lib/aiur/tmux.ex:891, src/lib/aiur/pane_manager.ex:635,652). Tests: none. Risk: low.
- **FI-TUI-005 · split_pane with -l N% sizing and :silent option** [api] — split_pane uses `-l N%` (not deprecated `-p`; tmux 3.5+ errors "size missing" on detached sessions); silent: true adds `-d` and skips the follow-up select-pane so hidden-window splits never drag the attached client there; returns trimmed pane id from `-P -F #{pane_id}` (src/lib/aiur/tmux.ex:447,455,467). Tests: src/test/aiur/tmux_test.exs. Risk: medium.
- **FI-TUI-006 · respawn_pane preserves pane id and grid position** [api] — `respawn-pane -k -t <pane>` kills the pane's command and starts the new one in the SAME pane id, so physical position never changes on slot reuse (src/lib/aiur/tmux.ex:576,579). Tests: src/test/aiur/pane_manager_test.exs ("sixth open replaces slot 1 via respawn-pane"). Risk: low.
- **FI-TUI-007 · new_hidden_window with no-server bootstrap fallback** [lifecycle] — Creates a detached background window; when tmux replies "no server running" (standalone TUI / --bg nohup BEAM) it falls back to `new-session -d -s <session> -n <name>`, so the first REPL spawn creates the session instead of failing headless (src/lib/aiur/tmux.ex:665,682,749). Tests: src/test/aiur/tmux_test.exs ("bootstraps the session when no server is running"). Risk: high.

Tests: src/test/aiur/tmux_test.exs (arg-shape tests). Risk: high.
