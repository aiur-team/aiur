# SD-408 — Remove deck voice_* events and unused TTS code

**Complexity:** 2
**Phase hint:** 6
**Area:** area:voice
**Depends on:** SD-407 — converse replaces the deck dictation path. Removing voice_* first would leave the deck with no voice.
**Serializes with:** SD-407 (sidecar voice files), SD-105 (`streamdeck_channel.ex`, `streamdeck_projection.ex`)

## Outcome
The deck has one voice path, `voice:converse`. The deck-only dictation events and the unused
client-side TTS code are gone.

## Context and evidence
`evidence/D-findings.md` §8. Deck-only events: `voice_start`, `voice_audio`, `voice_stop` in, and `voice`,
`voice_error`, `voice_closed` out (`streamdeck_channel.ex:199-236,310-330`), with helpers in
`streamdeck_channel/voice.ex:23-60`. `audio/tts.ts` has no importer in `src/`.

## Scope
- Daemon: delete the voice_* `handle_in` and `handle_info` clauses, `AiurWeb.StreamdeckChannel.Voice`
  `open_voice_session/0`, `stop_voice_session/1` and `drain_voice_messages/0`, and the `voice_session` assign.
  Keep `say` (text send) and the message helpers it uses.
- Keep the join snapshot `voice` availability entry (`streamdeck_projection.ex:35-41`), because the Talk key reads it.
- Sidecar: delete `audio/tts.ts`, `audio/relay.ts`, the voice_* parts of `channel.ts` (`:114-132,230-251,272-274`),
  and their exports in `audio/index.ts` and `channel-types.ts`. Move any `voiceHost.ts` logic that is still used to the
  converse client, and delete the rest.
- Keep `audio/playback.ts` and `audio/node-playback.ts` (SD-407 uses them), and `audio/stt.ts` only if converse still uses it.
- Delete the tests of the deleted modules.

## Non-goals
- Do not touch `Aiur.Voice`, `AiurWeb.VoiceChannel` or browser dictation.

## Existing owner and reuse target
- None. This is a deletion. `aiur-speech.ts` stays (it normalizes converse transcripts too).

## Contract and invariants
- An old sidecar that sends `voice_start` to a new daemon gets `{:error, %{reason: "unsupported"}}`, not a crash.
- No production module in `packages/streamdeck/src` imports a deleted file.

```text
deck -> voice_start {}   =>   reply {:error, %{"reason" => "unsupported"}}
```

## Refreshable implementation notes
- `src/lib/aiur_web/streamdeck_channel.ex:199-236,310-330`, `src/lib/aiur_web/streamdeck_channel/voice.ex`.
- `packages/streamdeck/src/channel.ts`, `audio/index.ts:31-35`, `audio/tts.ts`, `audio/relay.ts`, `voiceHost.ts`.
- Run `rg "voice_start|voice_audio|voice_stop|voice_closed|voice_error"` across `src/`, `packages/` and `docs/` until no
  result remains, except the "unsupported" clause.

## Acceptance criteria
1. `rg voice_start packages/streamdeck/src src/lib` finds only the "unsupported" clause.
2. `packages/streamdeck/src/audio/tts.ts` and `relay.ts` do not exist, and the sidecar typechecks.
3. A join followed by `voice_start` gets the "unsupported" reply, and the channel stays up.
4. The Talk key (SD-407) still works end to end on the real deck.
