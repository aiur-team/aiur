# SD-207 — Dial 3 instance switcher (#5964)

**Complexity:** 3
**Phase hint:** 2
**Area:** area:ui
**Depends on:** #5945 — the Stream Deck token route must accept per-instance bearer tokens (its AC2 and AC4 name the sidecar); without it each instance needs a second, deck-only credential list. #5968 (closed) — provides the `~/.aiur/remote-instances.yaml` registry this ticket reads. Soft: #5950 — instance roster for live/stale labels.
**Serializes with:** SD-103 (both edit `packages/streamdeck/src/main.ts` `connectDaemon`); SD-406 (settings "which instance")

## Outcome

One deck follows one Aiur instance at a time. Turning dial 3 browses the registered
instances on the strip; pressing dial 3 connects the deck to the shown instance. The
strip always names the instance the deck is following.

## Context and evidence

- The sidecar connects to one daemon from env `AIUR_PHOENIX_URL` with basic auth (`packages/streamdeck/src/main.ts:324-345`; token POST `channel.ts:68,89-92`).
- Registry from MIC-003 (#5968, merged as `6a7d6b445`): `~/.aiur/remote-instances.yaml`, `version: 1`, `instances.<name>.url`, `token_file` | `token_env` (`packaging/npm/aiur-cli/libexec/engine/remote.sh:3,97-140`).
- #5945 (OPEN, `agent:todo`) adds bearer tokens on the Stream Deck token route. #5950 (OPEN) adds a roster with heartbeat age. `evidence/B-findings.md` §7.
- Only the sidecar can reconnect, so this is sidecar-local; the server nav (SD-201) ignores dial 3.
- Dial index 2 has no turn or press action today; its press is half of the demo chord (`controller/state.ts:255`).

## Scope

- `packages/streamdeck/src/instances.ts`: read and validate the registry (same rules as `remote.sh`: https unless loopback; `token_file` must be mode 0600; never log the token). The env daemon (`AIUR_PHOENIX_URL`) is always the first entry, named `local`.
- `main.ts`: make `connectDaemon` take a target `{name, baseUrl, auth}`; on switch close the channel (stop voice as the `closed` handler does at `main.ts:370-380`), then connect to the new target; bearer auth via #5945's header.
- Dial 3 turn: move the highlighted entry on the strip (no network). Dial 3 press: connect. A press of dial 3 while dial 2 is also held is the demo chord, not a switch.
- Strip shows `<name>` and connection state (`connecting`, `connected`, `auth failed`, `unreachable`); with #5950, add live/stale and heartbeat age.
- Remember the last chosen instance in the sidecar config dir (next to `streamdeck-mic.json`, `sidecar-wiring.ts:27`); SD-406 owns the settings UI.
- Emulator: show the current instance name only; switching in the browser means opening the other dashboard's `/streamdeck`.

## Non-goals

- Server-side instance discovery or proxying one daemon through another.
- Showing several instances at once (decision 10: one at a time).
- Registry write helpers.

## Existing owner and reuse target

- Registry format and validation: `remote.sh` (MIC-003). Reconnect/backoff: `scheduleConnect` in `main.ts:326-336`.
- Bearer header: #5945's sidecar change.

## Contract and invariants

- At most one daemon channel is open at any time.
- A failed switch leaves the deck showing the failure and does not silently fall back to another instance.
- Tokens never appear in logs, debug output or the strip.

Worked shape:

```yaml
# ~/.aiur/remote-instances.yaml
version: 1
instances:
  nuc:
    url: https://nuc.tailnet.ts.net
    token_file: ~/.aiur/tokens/nuc-streamdeck   # 0600
```

```ts
// targets after load
[{ name: "local", baseUrl: "http://127.0.0.1:4000", auth: { kind: "basic" } },
 { name: "nuc", baseUrl: "https://nuc.tailnet.ts.net", auth: { kind: "bearer", tokenFile: "…" } }]
// strip while browsing: "Instance ◀ nuc ▶  · press to connect"
```

## Acceptance criteria

1. With a registry of two instances, dial 3 turn +1 highlights `nuc` and makes no network call.
2. Dial 3 press closes the local channel and opens one to `nuc` with `Authorization: Bearer`; only one channel is open after the switch.
3. An `http://` non-loopback URL or a 0644 `token_file` is refused with a strip message; the deck stays on its current instance.
4. A 401 from the target shows "auth failed" and does not fall back.
5. The token value never appears in debug output (`AIUR_STREAMDECK_DEBUG=1`).
6. Dial 2 + dial 3 held together toggles demo, not a switch.
7. On the real deck, switching to the NUC shows the NUC's tickets; switching back shows the PC's.
