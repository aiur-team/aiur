# SD-407 — Deck joins voice:converse (hold to talk, barge-in)

**Complexity:** 4
**Phase hint:** 5
**Area:** area:voice
**Depends on:** #4142 — adds `AiurWeb.VoiceConverseChannel` on `voice:converse` (does not exist at `6a7d6b445`); #4145 — defines the barge-in client contract (`interrupted`, `playback_state`, echo-cancel or half-duplex fallback) that the deck must follow; #5729 — adds the non-browser voice authority (`voice_authority %{kind: :device}`), which the deck copies as a `:streamdeck` kind; SD-406 — mic and speaker device choice; SD-201 — hold-key input.
**Serializes with:** SD-408 (the same channel and sidecar voice files), SD-406 (audio device settings)

## Outcome
The operator holds a key to talk to the Executor, or to the selected ticket's agent. The reply plays
on the PC speakers. Speaking (holding the key) while a reply plays stops it. The deck uses the
same conversation session as the dashboard.

## Context and evidence
`evidence/D-findings.md` §8. The deck has its own dictation path (`voice_start`/`voice_audio`/`voice_stop`,
`streamdeck_channel.ex:199-236`) that only transcribes. `voice:converse` is planned in #4142 (blocked by
MP-E6-C4-T01, MP-E5-C2-T01 and DESIGN-E6). The deck socket is token-authenticated (`streamdeck_socket.ex:11`),
not browser-cookie authenticated, so it needs a non-browser authority like #5729's device authority.

## Scope
- Daemon: register `voice:converse` on `AiurWeb.StreamdeckSocket` (next to `streamdeck:fleet`). Pass
  `voice_authority %{kind: :streamdeck}` with limiter authority `"streamdeck:" <> instance_key`.
- Join with `mode: "converse"` and a target from `VoiceTargets` (`executor` or `ticket:<id>`). The target is the
  selected ticket on the ticket page, or else the Executor.
- Sidecar: a `ConverseClient` in `packages/streamdeck/src/audio/converse.ts`:
  - key down: open capture on the chosen mic and send `audio` chunks (reuse `audio/aggregate.ts` framing);
  - key up: send `end`;
  - `audio` events: write PCM to `audio/node-playback.ts` on the chosen speaker, at the rate from the
    event `format` (for example `pcm_16000`), not the fixed 44.1 kHz;
  - `interrupted` or a new key down during playback: close playback, drop the queued chunks for that turn, and send
    `playback_state: stopped`;
  - `draft` to a ticket agent: the strip shows the draft, press Send for `confirm_draft`, press Cancel for `discard_draft`.
- The strip shows the conversation state (listening, thinking, speaking) and the last assistant text.

## Non-goals
- Do not delete the old voice_* path (SD-408).
- No phone or watch support. No wake word.

## Existing owner and reuse target
- `AiurWeb.VoiceConverseChannel` (#4142), `AiurWeb.VoiceTargets`, `VoiceSessionLimiter`.
- Sidecar: `audio/capture.ts`, `audio/aggregate.ts`, `audio/playback.ts`, `audio/node-playback.ts`.

## Contract and invariants
- Only one converse session runs per deck. A second hold re-uses the session within its grace time.
- Playback never continues after `interrupted` for that turn.
- When voice is unavailable (no ElevenLabs key), the hold key shows the reason, and no audio leaves the PC.

```text
deck -> join voice:converse {mode: "converse", target: "ticket:5181", client: {kind: "streamdeck"}}
deck -> audio {chunk: <base64 pcm_16000>} ... end {}
daemon -> state {value: "thinking"}; assistant_text {...}; audio {format: "pcm_16000", chunk}; audio_done {}
deck (key down during audio) -> playback_state {state: "stopped", turn_id}
```

## Refreshable implementation notes

- Sidecar: new `audio/converse.ts`. `audio/node-playback.ts:15-17`: make `--rate` a parameter.
- `packages/streamdeck/src/channel.ts`: a second channel join on the same socket.

## Acceptance criteria
1. Holding the Talk key on the ticket page and saying a sentence gives an assistant reply that is heard on the speakers.
2. Holding the key during a reply stops playback within 300 ms, and the daemon gets `playback_state: stopped`.
3. With no ElevenLabs key, the Talk key shows "Aiur has no ElevenLabs API key" and opens no capture.
4. A ticket-agent draft is delivered only after Send is pressed.

## Test that fails without the change
- `packages/streamdeck/test/audio/converse.test.ts` with fake channel and playback ports: criterion 2 (an `interrupted` event
  closes playback and sends `playback_state`), and criterion 4.
- `src/test/aiur_web/streamdeck_converse_join_test.exs`: a deck token joins `voice:converse`. A missing token is refused.
