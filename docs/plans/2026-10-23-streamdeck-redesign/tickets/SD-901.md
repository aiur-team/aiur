**Depends on:** every other SD ticket in this pack (it is the feature-acceptance capstone)

## Outcome

Kevin uses the physical Stream Deck and the browser `/streamdeck` emulator for one working
session and sees the same images, the same counts and the same meters as the Build page. The
docs describe the deck as it now behaves.

## Context and evidence

The redesign replaces deck-only logic with a thin adapter over the Build page read models
(plan: `docs/plans/2026-10-23-001-feat-streamdeck-redesign-plan.md`). Each member ticket proves
its own slice. This ticket proves the whole feature end to end and removes stale docs.

## Scope

- Run the manual test recipe in `docs/manual-testing.md` with the deck sidecar connected, and
  record what each view, the ticket page, the strip and the meters show.
- Compare deck values with the Build page for the same instant: strip counts vs NowRows,
  meters vs Build.Usage, feature % vs the Features list (#5998), epic remaining vs the Epics
  list (#5999).
- Sweep `website/docs-app/guide/stream-deck.md` and `docs/streamdeck-channel.md`: remove every
  description of deleted behavior (grid buckets, Logs mode, test-mic key, deck voice_* events,
  parity contract) and check that each member ticket's doc edits agree.

## Non-goals

  deferred ledger (P2/P3).
