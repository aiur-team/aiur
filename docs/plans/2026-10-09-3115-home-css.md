# Contract

Implement #3115 against main, using the checked-in immutable design and the merged

## Implementation

1. Census CSSOM rules against the full dataset/view/theme/palette, URL, interaction,
   hover, skeleton, boundary and reduced-motion matrix. Record source lines,
   matches, unlisted zero matches and provably shadowed declarations as artifacts.
2. Populate home.css in H-then-C order. Scope shared H selectors with :where,
   remove only enumerated dead selectors, preserve keyframes/property/fallbacks,
   and reset measured product leaks. Keep every new file below 500 lines.
3. Transplant identical home roots into an authenticated fixture-origin document,
   copying wrapper inheritance and geometry. Compare longhands, pseudo-elements,
   custom properties, keyframes/property and selected screenshots. Check fixture
   routes with empty and real sheets, with explicit button/link preconditions.
4. Wire the focused browser command into npm test, freeze literal inks in the existing
   theme ExUnit file, validate serving unchanged,
   and measure white-on-fill contrast. Run mutation checks in an isolated worktree.

## Risks and verification

CSS shorthand folding can disturb longhands: remove only declarations with identical
selector/context and a later declaration of the same property and sufficient importance.
Inherited wrapper geometry and animation sampling must be identical on both pages.
Respect the reduced-motion exclusions specified in the ticket. Never broaden the
allowlist to hide mismatches. Existing live markup does not yet use these rules.

Run affected browser specs through the package runner, compile/format/affected tests,
lint and repository checks. Review the pushed diff, mark the PR ready, and hand to
CI on main. No manual TUI scenario applies to this internal stylesheet.
