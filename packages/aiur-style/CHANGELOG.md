# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-27

### Added

- Light/dark design tokens, contrast pairs, self-hosted fonts and brand assets.
- Buttons, announcement banner, topbar, brand reveal and theme toggle.
- Footer, command box, tabs, scroll cue, feature grid and prose styles.
- Dashboard shell, responsive navigation and page frame.
- Flow field and diagonal-line backgrounds with reduced-motion support.
- React wrappers and VitePress adapter styles.
- External pre-paint theme initializer with legacy preference migration.
- Installed-tarball export checks and tag-triggered npm provenance publishing.

## [0.0.0] - 2026-10-01

### Added

- Package scaffold: build pipeline, dist validation, test harness, and CI automation
- TypeScript strict mode configuration
- Gallery scaffolding for future component documentation
- Playwright visual test infrastructure
- Node.js test suite for dist validation (exports, CSP safety, file presence)
- Base CSS layer structure with box-sizing reset, visually-hidden utility, and reduced-motion support
- Empty JavaScript barrel for future component behaviors
